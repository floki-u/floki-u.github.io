1. RunLoop 概述

1.1 什么是 RunLoop？

官方定义：RunLoop 是一个事件处理循环，用于持续调度和协调接收到的事件。

大白话：RunLoop 就像一个永不停歇的门卫，不断地：

  • 👂 监听事件（触摸、定时器、网络）
  • 🏃 处理任务
  • 😴 休眠等待（没事时睡觉，节省 CPU）

1.2 系统架构

关键点：

  • CFRunLoop 是核心实现（开源）
  • NSRunLoop 是 OC 封装（不开源）
  • 底层基于 mach_msg() 实现线程休眠

3. RunLoop Mode 深入解析

3.1 Mode 的本质

定义：Mode 是一个过滤器，决定了 RunLoop 在某个状态下处理哪些 Source/Timer/Observer。

比喻：

  • 🏪 RunLoop 是一个24 小时便利店
  • 🏷️ Mode 是不同的营业模式：
    • Default 模式：正常营业，处理所有商品
    • Tracking 模式：清仓大甩卖，只处理滚动事件
    • UIInitialization 模式：装修期，只处理初始化
