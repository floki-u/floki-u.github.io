Yujournal · 余记

每天记一点，账目留在本机。

打开余记 ↗GitHub 项目 ↗
01 / QUICK ENTRY

语音与截图，少打几个字

应用内长按说话，或识别付款截图；一次整理多笔收入与支出，保存前统一核对金额、方向和日期。

02 / LOCAL FIRST

离线记录，完整备份

账目保存在当前设备，不上传云端。支持导出、导入完整 .yuji 备份，用于换机和保留历史记录。

03 / DAILY LIFE

收支、资产与存钱计划

用日历查看日、月、年账目，设置固定收支和存钱目标，生成报告长图；还可收集徽章、佩戴并解锁主题。

安装与开始使用

  1. 用 iPhone Safari 打开余记，选择“分享 → 添加到主屏幕”，保持“打开为网页 App”开启。
  2. 从主屏幕图标打开，首次联网完成程序缓存后即可离线记账。建议始终使用这个固定入口保存正式账目。
  3. 语音与截图识别资源按需准备。输入或识别后先核对清单，再一次确认入账。

也可通过 iPhone 安装页 下载 Web Clip 描述文件，然后在“设置 → 已下载描述文件”完成安装。描述文件只添加可移除的网页入口，不包含设备管理、VPN 或账本。

这是网页应用，无需上架 App Store、付费苹果开发者账号或定期重新签名。应用联网更新程序缓存后，重开即可使用新版。

便捷记账与离线识别

本机语音包约 98 MiB，首次按需下载，录音不上传。关闭录入浮层或切换应用内页面时继续下载，支持手动暂停和分段续传；iOS 锁屏、切到其他 App 或结束进程后仍可能暂停执行。

截图识别支持裁剪、查看原文和多笔确认。快捷指令提供图片分享识别和语音录入入口，添加步骤见 快捷输入说明。余记不会后台读取微信、支付宝或银行 App 的流水。

支持多币种与自动获取的日参考汇率，历史账目保留入账时的折算结果。报告可生成为本机 PNG 长图，通过系统分享面板保存到照片。

本机数据与换机

在“我的”中导出完整 .yuji 备份，换设备后导入。完整备份可包含账目、计划、固定收支、个人资料及已保留的截图，并可选择密码保护。

清除网站数据前先导出备份。移除主屏幕图标或 Web Clip 不保证同时释放网页缓存；需要释放识别资源时，使用应用里的清理按钮，不影响账目。

版本与反馈

当前为早期版本，主要面向 iPhone 与新版 Safari。自动化测试和浏览器验证范围、仍需真机确认的项目见 测试说明。

使用问题见 常见问题；反馈可通过 GitHub Issues 提供系统版本和复现步骤，示例账目请使用虚构数据。
