macOS 14+Apple Silicon实验版 · 1.3.0

Wallume

Mac 动态壁纸与视频锁屏工具。

下载实验版 ↗GitHub 项目 ↗
01 / LOCAL

本地图片与视频

支持 PNG、JPG、HEIC、MOV 和 MP4，也可以导入素材文件夹。图片与视频保存在本机，不上传。

02 / DISPLAYS

多显示器分配

为内建屏和外接显示器分别选择素材。视频桌面墙纸在 Wallume 运行期间播放。

03 / LOCK SCREEN

原生动态锁屏

macOS 26 及以上支持实验性的原生视频锁屏。素材准备完成后，在系统墙纸设置中选择并确认。

安装与使用

  1. 从 GitHub Releases 下载最新实验包，解压后将 Wallume.app 放入“应用程序”。
  2. 打开“画面库”，导入图片或视频，再为显示器选择画面。
  3. 需要视频锁屏时，在“锁屏同步”中准备素材，然后到“系统设置 → 墙纸”确认选择。

完整步骤见 安装与卸载说明。

兼容性

当前下载包适用于 Apple Silicon。macOS 14 / 15 支持桌面墙纸；原生动态锁屏需要 macOS 26 及以上。

当前实验包尚未经过 Apple 公证。多显示器、睡眠唤醒和锁屏切换仍在验证中。macOS 27 的实机验证尚未完成。

反馈与许可

遇到问题可以在 GitHub Issues 提供 macOS 版本、芯片类型、显示器数量和复现步骤。请勿附上私人图片或视频。
