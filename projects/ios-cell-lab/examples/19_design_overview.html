🌐 设计模式总览 — 7 大类 App 横向对比

把 App 按"用户使用场景"分成 7 大类，对比它们在信息架构、视觉语言、交互范式、商业目标上的共性和差异。这是产品 / 设计 / 开发都该掌握的"App 通识"。

✨ 跨 App 的「共性」— 它们都用了这些

① TabBar 5 选 1

底部 4-5 个 Tab 是绝对主流。原因：拇指能轻松触达，5 个之内不用滚动。

微信 4、抖音 5、淘宝 5、小红书 5、Apple 设置无 TabBar（单层级）

② 红色徽标

系统级共识。即使品牌色不是红，徽标也用红色。心理学上"红 = 注意"。

微信、抖音、QQ、Instagram、Twitter、邮件全用红色

③ 下拉刷新

Loren Brichter 在 Tweetie 发明（2008），现在已成"列表标配"。用户不需教学。

所有内容流类 App 都支持，缺失反而被觉得"做得不完整"

④ 沉浸式头部

头图视差 + 渐变导航栏。从 Spotify 推广到电商详情、个人主页、商品详情。

小红书博主主页、淘宝商品详情、网易云专辑页都用

⑤ 双击交互

Tab 双击滚到顶部 / 双击点赞 / 双击切换。给重度用户的"隐藏快捷键"。

Instagram 双击点赞 → 抖音、小红书、微博跟进

⑥ 长按菜单

长按消息/图片/链接弹"更多动作"。比按钮更隐蔽，给"知道的用户"加分。

iMessage Tapback、微信引用、Telegram 转发都是长按

⑦ 骨架屏 / Shimmer

替代菊花已成共识。Facebook 2017 发明，2 年内全行业普及。

小红书、微博、淘宝、知乎都用

⑧ 半屏 Modal Sheet

评论、分享、详情等次级页面用半屏 sheet 弹出。不打断主上下文。

iOS 15+ 的 UISheetPresentationController 把它做成系统能力

⑨ Modal 转场动画

"来源即去向" — 元素从哪来回哪去。Story 关闭时缩回头像圈是经典。

Apple Photos、Instagram Story、抖音详情转场

🎯 不同类型 App 的「差异点」— 看清各自取舍

📌 工具 vs 内容：信息密度的取舍

工具类追求"一屏看更多"，行高紧凑（微信会话列表 ~64pt）；内容类追求"沉浸感"，单屏甚至只放 1-2 个内容（抖音全屏、小红书双列大图）。

学习点：根据"用户希望处理多少 vs 欣赏多少"决定行高

📌 电商 vs 社区：CTA 的位置

电商把"购买/加购"按钮做在最显眼位置，价格用大号红字；社区把"点赞/收藏"放右下小图标，绝不抢戏。

学习点："想让用户做的事"决定按钮的视觉权重

📌 短视频 vs 长视频：默认播放

短视频默认自动播放、循环、有声（抖音）；长视频默认静音封面（B站、爱奇艺）。原因是短视频的"选择成本低"，长视频"播错很烦"。

学习点：用户决策成本决定默认行为

📌 金融 vs 娱乐：颜色心理学

金融用蓝色（信任、稳定）+ 大量留白（庄严感）；娱乐用高饱和（兴奋）+ 紧凑布局（信息流）。

学习点：颜色 = 情绪，与功能匹配

📌 系统 vs 业务：图标风格

系统用 SF Symbols 线性图标 + 彩色背景方块（统一感）；业务用插画式图标（差异化、品牌感）。

学习点：偏功能就线性，偏品牌就插画

📌 国内 vs 海外：信息密度差异

国内同一屏挤更多信息（淘宝首页 vs Amazon），因为屏小、人多、注意力短；海外更多留白，重视呼吸感。

学习点：本地化不只是翻译，还是排版习惯

🏆 总结 — 12 条通用设计法则

1️⃣ 拇指热区原则

iPhone 屏幕越来越大，但拇指能舒适触达的区域只有右下 1/3。所有高频操作（点赞、发布、关闭）都该在这。

2️⃣ 信息层级最多 3 层

Tab → 列表 → 详情。再深用户会迷路。如果功能多，用 search 或快捷入口替代深层级。

3️⃣ 加载态比成功态更重要

用户能容忍慢，但容忍不了"不知道发生了什么"。骨架屏 / 进度条 / Toast 必须有。

4️⃣ 反馈延迟 ≤ 100ms

用户感知"流畅"的临界点。任何点击都要在 100ms 内有视觉反馈（即使数据还没回来）。

5️⃣ 颜色语义化

红 = 危险/通知 / 绿 = 成功/确认 / 蓝 = 信任/链接 / 黄 = 警告。不要随意用。

6️⃣ 主操作只有一个

每个页面只有一个最高优先级 CTA。多个"主按钮"会让用户犹豫。

7️⃣ 系统组件优于自定义

用户对系统设计有肌肉记忆。能用 UICollectionLayoutListConfiguration 就别自己撸。

8️⃣ Dark Mode 不是反色

不是简单 invert。需要重新设计层级（深色背景下层级用浅黑表达）。

9️⃣ 无障碍是必修

VoiceOver、Dynamic Type、对比度。不是加分项，是基本盘。Apple 审核会卡。

🔟 动效要服务于功能

不是为了炫。Story 关闭缩回头像 = 告诉用户"它来自这里"，是空间感。

1️⃣1️⃣ 不要过度设计

淘宝首页之所以"乱"，是因为它要在一屏内卖出尽可能多商品。设计服务商业，不是反过来。

1️⃣2️⃣ 永远在 iPhone SE 上验证

4.7 寸屏幕能用，13 Pro Max 才会好用。从最小屏开始。

🎓 推荐学习路径 — 怎么把这些组件融会贯通

1
🟢 先打牢"反离屏"基本功

每天看到的所有 cell 都问自己一个问题："这个圆角/阴影离屏了吗？怎么消除？"练 1 周后形成肌肉记忆。

→ MessageCell → NewsCell → 反例对比
2
🟡 掌握 6 种核心组件

骨架屏、左滑菜单、展开卡片、视差头图、瀑布流、下拉刷新。这 6 个组件覆盖业务 80% 场景。

→ Skeleton → Swipe → Expandable → Parallax → Waterfall → Refresh
3
🟣 拆解头部 App 的设计

每天用一个 App，问"它为什么这么设计"，写一篇 200 字的 mini 复盘。坚持 1 个月，设计感会突飞猛进。

→ TabBar → 电商 → 抖音 → 聊天 → Story → Apple 设置
4
🔵 通过仿写练习沉淀

挑一个你最喜欢的 App 的某个页面，1 周内仿写出 80% 的视觉效果 + 60% 的交互。每仿写一个，吸收 5+ 个细节。

推荐仿写清单
5
🟠 阅读 Apple HIG（人机界面指南）

这是 Apple 官方的"设计圣经"。每周读一章，半年读完，设计水平 = 中级 → 高级。
地址：developer.apple.com/design/human-interface-guidelines

6
🔴 持续关注 WWDC

每年 6 月 WWDC 会发布新 API + 新设计语言。第一时间用到项目里，永远比同行快一步。
推荐 session：「What's new in UICollectionView」、「Modern cell configuration」、「Design with iOS pickers, menus and actions」。
