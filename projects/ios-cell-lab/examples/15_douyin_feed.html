🧠 沉浸式设计的 5 个核心原则

1. 单卡全屏 · 一屏一个视频，让用户注意力集中，无信息焦虑
2. 上滑切换 · 沿用 Tinder 的"滑卡"心智，比横滑更符合手指动作（拇指上下移动比左右更自然）
3. 操作右置 · 拇指操作热区在右下，所有交互按钮（点赞/评论/分享）都在右侧
4. 永远黑底 · 不切换深浅色，让视频内容自由表达
5. 隐性教学 · 头像下方的 "+" 提示关注；右侧操作栏的数字暗示"很多人都在做"

📦 完整实现 — UICollectionView 全屏分页

关键技术：UICollectionViewFlowLayout 横向 → 改为竖向 + 整页对齐 + 视频复用

1️⃣ Layout —— 竖向分页

// 用 UICollectionView 而不是 UIScrollView 的原因： // 复用！100 个视频，只创建 3 个 cell（前一个 + 当前 + 后一个） - (UICollectionView *)setupCollectionView { UICollectionViewFlowLayout *layout = [UICollectionViewFlowLayout new]; layout.minimumLineSpacing = 0; layout.minimumInteritemSpacing = 0; layout.itemSize = self.view.bounds.size; layout.scrollDirection = UICollectionViewScrollDirectionVertical; UICollectionView *cv = [[UICollectionView alloc] initWithFrame:self.view.bounds collectionViewLayout:layout]; // ⭐ 关键：开启分页 cv.pagingEnabled = YES; cv.contentInsetAdjustmentBehavior = UIScrollViewContentInsetAdjustmentNever; cv.showsVerticalScrollIndicator = NO; cv.backgroundColor = [UIColor blackColor]; [cv registerClass:[VideoCell class] forCellWithReuseIdentifier:@"video"]; return cv; }

2️⃣ VideoCell —— 视频播放 + 复用

@interface VideoCell : UICollectionViewCell @property (nonatomic, strong) AVPlayerLayer *playerLayer; - (void)configureWithVideo:(VideoModel *)model; - (void)play; - (void)pause; @end @implementation VideoCell { AVPlayer *_player; VideoModel *_currentModel; } - (instancetype)initWithFrame:(CGRect)frame { if (self = [super initWithFrame:frame]) { _playerLayer = [AVPlayerLayer layer]; _playerLayer.videoGravity = AVLayerVideoGravityResizeAspectFill; _playerLayer.frame = self.contentView.bounds; [self.contentView.layer addSublayer:_playerLayer]; } return self; } - (void)configureWithVideo:(VideoModel *)model { if (_currentModel == model) return; _currentModel = model; // ⭐ 核心：用 VideoPreloader 拿预加载好的 AVPlayerItem AVPlayerItem *item = [[VideoPreloader shared] playerItemForVideo:model]; _player = [[AVPlayer alloc] initWithPlayerItem:item]; _player.actionAtItemEnd = AVPlayerActionAtItemEndNone; // 不暂停 _playerLayer.player = _player; // ⭐ 循环播放 [[NSNotificationCenter defaultCenter] addObserver:self selector:@selector(loop:) name:AVPlayerItemDidPlayToEndTimeNotification object:item]; } - (void)loop:(NSNotification *)note { [_player seekToTime:kCMTimeZero]; [_player play]; } - (void)play { [_player play]; } - (void)pause { [_player pause]; } - (void)prepareForReuse { [super prepareForReuse]; // ⭐ 复用前必须清 [_player pause]; _player = nil; _playerLayer.player = nil; [[NSNotificationCenter defaultCenter] removeObserver:self]; } @end

3️⃣ ⭐⭐⭐ 核心：VideoPreloader 预加载（决定流畅度的关键）

// 抖音流畅的秘密：用户看到 N 时，N+1、N+2 已经下载好 @interface VideoPreloader : NSObject + (instancetype)shared; - (void)preloadVideo:(VideoModel *)model; - (AVPlayerItem *)playerItemForVideo:(VideoModel *)model; @end @implementation VideoPreloader { // ⭐ LRU 缓存：最多保留 5 个预加载好的 PlayerItem NSCache<NSString *, AVPlayerItem *> *_cache; } - (instancetype)init { if (self = [super init]) { _cache = [[NSCache alloc] init]; _cache.countLimit = 5; } return self; } - (void)preloadVideo:(VideoModel *)model { if ([_cache objectForKey:model.url]) return; // ⭐ 用 AVURLAsset，提前 loadValuesAsynchronouslyForKeys AVURLAsset *asset = [AVURLAsset URLAssetWithURL:[NSURL URLWithString:model.url] options:nil]; [asset loadValuesAsynchronouslyForKeys:@[@"playable", @"duration", @"tracks"] completionHandler:^{ dispatch_async(dispatch_get_main_queue(), ^{ AVPlayerItem *item = [AVPlayerItem playerItemWithAsset:asset]; // ⭐ 预加载前 5 秒 item.preferredForwardBufferDuration = 5.0; [_cache setObject:item forKey:model.url]; }); }]; } - (AVPlayerItem *)playerItemForVideo:(VideoModel *)model { AVPlayerItem *item = [_cache objectForKey:model.url]; if (item) { [_cache removeObjectForKey:model.url]; // 用了就移出，避免被多 player 共用 return item; } // 缓存未命中：实时加载 AVURLAsset *asset = [AVURLAsset URLAssetWithURL:[NSURL URLWithString:model.url] options:nil]; return [AVPlayerItem playerItemWithAsset:asset]; } @end

4️⃣ ViewController —— 滑动联动 + 预加载触发

@implementation FeedViewController { NSInteger _currentIndex; } // 滚动停止时切换播放 - (void)scrollViewDidEndDecelerating:(UIScrollView *)scrollView { NSInteger page = scrollView.contentOffset.y / scrollView.bounds.size.height; if (page == _currentIndex) return; _currentIndex = page; // ⭐ 1. 切换播放 [self.collectionView.visibleCells enumerateObjectsUsingBlock:^(VideoCell *cell, ...) { NSIndexPath *ip = [self.collectionView indexPathForCell:cell]; if (ip.item == page) { [cell play]; } else { [cell pause]; } }]; // ⭐ 2. 预加载下两个 if (page + 1 < self.videos.count) { [[VideoPreloader shared] preloadVideo:self.videos[page + 1]]; } if (page + 2 < self.videos.count) { [[VideoPreloader shared] preloadVideo:self.videos[page + 2]]; } // ⭐ 3. 接近底部时拉新一页 if (page >= self.videos.count - 3) { [self loadMoreVideos]; } } @end
为什么用 UICollectionView 不用 UIScrollView？
复用！100 个视频如果用 ScrollView 就要创建 100 个 AVPlayer，必崩。CollectionView 屏幕上最多 3 个 cell，3 个 player，内存稳定。

🚀 抖音同款的 5 个性能优化点

优化点做法收益
视频预加载用户在 N 时预下 N+1, N+2切换无白屏，体感"秒开"
分段预加载preferredForwardBufferDuration = 5s不浪费流量，5 秒够用户决定划走
HEVC 编码视频用 H.265 编码上传同画质带宽 -40%
首帧立即显示cover image 占位 → 视频起播渐显首帧时间从 800ms 降到 100ms
边播边缓存用 AVAssetResourceLoader hook 网络流已播放的不用重下载，回滑秒开

⚖️ 反例 vs 正例

❌ 反例：每个视频独立 ViewController

用 UIPageViewController 每页一个 VC
→ 100 个视频 = 100 个 VC + 100 个 player
→ 内存峰值 800MB+，第 30 个就崩

✅ 正例：UICollectionView + Cell 复用

屏幕上最多 3 个 cell，3 个 player
→ 内存稳定 200MB
→ 滚动 1000 个视频也不崩

🎓 可借鉴的设计创新点

借鉴 1：滑动手势 = 行为信号
上滑 = 不喜欢（隐式负反馈）。即使不点❤️，"看完率"和"完播率"就是推荐算法的核心信号。这个设计是抖音算法领先的根基之一。
借鉴 2：双击点赞
手指停在视频上的概率高，比点右下角的小心心方便。有"心心动画"反馈，体验闭环。Instagram 发明，TikTok 沿用，已成标准。
借鉴 3：长按拖动进度
抖音视频底部默认无进度条。长按视频暂停 + 显示进度条。"默认隐藏控件，按需召唤"是沉浸式 App 的金科玉律。
借鉴 4：评论页底部弹出而非全屏
评论是 sheet 滑上来盖住下半屏，视频继续在上半屏播放。让用户"边看边评"，不打断内容消费。
借鉴 5：滑动卡顿时的"灵魂震荡"
切换视频时如果加载慢，用一个轻微的"卡顿震荡"反馈，比 loading 圈更有"在努力"的感觉。是降低焦虑的微设计。
