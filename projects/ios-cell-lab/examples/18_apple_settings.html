🧠 Apple 设置页的 7 条设计原则

原则表现背后动机
1. 大标题 页面顶部 34pt 粗体大标题，下滑后变小 明确"我在哪一页"，避免迷失
2. InsetGrouped 白色卡片 + 12pt 圆角，左右留 16pt 边距 视觉模块化，强化"这是一组"
3. 彩色图标 圆角矩形（28×28）背景 + 白色 SF Symbols 类别识别度高，第一眼分类
4. 17pt 字号 所有标签 17pt 系统字 无障碍友好，老年人也能看清
5. 右侧 Chevron 所有可点击 row 都有 › 明确"可以进入下一层"
6. Section Footer 帮助文案 section 底部一段灰色小字 就近解释，不需要单独"说明"页
7. 状态值左置 chevron "无线局域网 .... CMCC-5G ›" 不进入页面也能知道当前状态

📦 完整实现 — UICollectionView + List Configuration（iOS 14+）

无需自定义 cell，全部用 Apple 系统组件，与系统设置一模一样

1️⃣ 数据模型

@interface SettingItem : NSObject @property (nonatomic, copy) NSString *title; @property (nonatomic, copy) NSString *subtitle; // 右侧状态值 @property (nonatomic, copy) NSString *iconName; // SF Symbols 名 @property (nonatomic, strong) UIColor *iconBgColor; @property (nonatomic, assign) SettingAccessoryType accessoryType; // chevron / switch / badge @property (nonatomic, copy) void (^onTap)(void); @end

2️⃣ Layout —— 一行代码搞定 InsetGrouped 风格

- (UICollectionViewLayout *)makeListLayout { // ⭐ 系统提供的 list configuration，appearance 是 InsetGrouped UICollectionLayoutListConfiguration *cfg = [[UICollectionLayoutListConfiguration alloc] initWithAppearance:UICollectionLayoutListAppearanceInsetGrouped]; cfg.headerMode = UICollectionLayoutListHeaderModeSupplementary; // 支持 section header cfg.footerMode = UICollectionLayoutListFooterModeSupplementary; // 支持帮助文案 return [UICollectionViewCompositionalLayout layoutWithListConfiguration:cfg]; }

3️⃣ Cell —— 用 UIListContentConfiguration（iOS 14+）

// ⭐ 完全不需要自定义 cell！用系统的 UICollectionViewListCell UICollectionViewCellRegistration *cellReg = [UICollectionViewCellRegistration registrationWithCellClass:[UICollectionViewListCell class] configurationHandler:^(UICollectionViewListCell *cell, NSIndexPath *ip, SettingItem *item) { // ⭐ 内容配置 UIListContentConfiguration *content = [cell defaultContentConfiguration]; content.text = item.title; // ⭐ 彩色图标方块（系统设置同款） if (item.iconName) { UIImage *symbol = [UIImage systemImageNamed:item.iconName]; symbol = [symbol imageWithTintColor:[UIColor whiteColor] renderingMode:UIImageRenderingModeAlwaysOriginal]; // 用 image 的 inset 做出"圆角彩色背景"效果 UIImage *iconWithBg = [self renderIcon:symbol bg:item.iconBgColor]; content.image = iconWithBg; content.imageProperties.cornerRadius = 6; } cell.contentConfiguration = content; // ⭐ 右侧 accessory（chevron / switch / detail） NSMutableArray<UICellAccessory *> *accessories = [NSMutableArray array]; if (item.subtitle) { // 右侧文字，比如 "无线局域网 ... CMCC-5G" UICellAccessoryLabel *label = [[UICellAccessoryLabel alloc] initWithText:item.subtitle]; [accessories addObject:label]; } switch (item.accessoryType) { case SettingAccessoryDisclosure: [accessories addObject:[UICellAccessoryDisclosureIndicator new]]; break; case SettingAccessorySwitch: { // ⭐ Switch 也是系统的 cell accessory UISwitch *sw = [UISwitch new]; sw.on = item.switchOn; UICellAccessoryCustomView *customView = [[UICellAccessoryCustomView alloc] initWithCustomView:sw placement:UICellAccessoryPlacementTrailing]; [accessories addObject:customView]; break; } case SettingAccessoryBadge: { // 红色 badge（"通用 ① ›" 那种） UIView *badgeView = [self badgeView:item.badgeText]; UICellAccessoryCustomView *cv = [[UICellAccessoryCustomView alloc] initWithCustomView:badgeView placement:UICellAccessoryPlacementTrailing]; [accessories addObject:cv]; [accessories addObject:[UICellAccessoryDisclosureIndicator new]]; break; } } cell.accessories = accessories; }];

4️⃣ DataSource + Snapshot

self.dataSource = [[UICollectionViewDiffableDataSource alloc] initWithCollectionView:self.collectionView cellProvider:^UICollectionViewCell *(UICollectionView *cv, NSIndexPath *ip, SettingItem *item) { return [cv dequeueConfiguredReusableCellWithRegistration:cellReg forIndexPath:ip item:item]; }]; // ⭐ Snapshot —— 数据驱动 UI NSDiffableDataSourceSnapshot *snap = [NSDiffableDataSourceSnapshot new]; [snap appendSectionsWithIdentifiers:@[@"profile", @"system", @"notification", @"general"]]; [snap appendItemsWithIdentifiers:self.profileItems intoSectionWithIdentifier:@"profile"]; [snap appendItemsWithIdentifiers:self.systemItems intoSectionWithIdentifier:@"system"]; // ... [self.dataSource applySnapshot:snap animatingDifferences:YES];
这套方案的优势：
· 0 行自定义 cell 代码，全部用系统组件
· 自动支持 Dynamic Type（无障碍字号）
· 自动支持 Dark Mode
· 自动支持 VoiceOver
· iOS 升级后自动获得新设计（比如 iOS 17 的更圆角）

⚖️ 反例 vs 正例

❌ 反例：自己画一套

自定义 cell + 手算图标圆角 + 自己处理 Dark Mode
→ 几百行代码
→ 系统升级要跟着改
→ 字号、配色和系统不一致，老用户感到陌生
→ VoiceOver 要自己配

✅ 正例：UICollectionLayoutListConfiguration

系统组件全包
→ 50 行代码完工
→ 永远跟系统同步
→ 用户零学习成本
→ 无障碍 / Dark Mode / Dynamic Type 全自动

🎓 Apple 设计中可借鉴的 5 个点

借鉴 1：彩色分类图标的"形状语言"
所有图标都是 28×28 圆角矩形 + 白色 SF Symbol。这种"统一容器形状 + 不同填充色"的设计，识别度极高，可大量用在功能列表。
借鉴 2：状态值"前置"减少跳转
WiFi 名、蓝牙状态都直接显示在 row 上。用户不用进入下一层就能知道，是优秀 UX 的标志。
借鉴 3：Section Footer 就近解释
解释文案放在 section 底部 13pt 灰字，而不是单独的"说明"页。就近原则降低用户理解成本。
借鉴 4：大标题 → 小标题的渐变折叠
navigationItem.largeTitleDisplayMode = .always 一行启用。下滑时大标题自动折叠到导航栏。这是一种"层级感 + 节省空间"的优雅方案。
借鉴 5：搜索栏的"按需展开"
navigationItem.searchController = ...
默认折叠，用户下拉才出现搜索框。不抢占首屏但触手可及。微信、淘宝、知乎都跟进了这个模式。
