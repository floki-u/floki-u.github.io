🧠 同样是"双列流"，设计哲学完全不同

维度淘宝（转化导向）小红书（探索导向）
头部颜色 橙红渐变（品牌 + 制造紧迫感） 白色（让内容主导）
顶部信息 搜索框 + 金刚区（10+ 入口） 关注/发现/附近 3 Tab
商品图比例 正方形为主（标准化、便于对比） 不固定（瀑布流，鼓励停留）
视觉重点 价格（红色加粗大字） 标题 + 点赞数（社交证据）
数据展示 已售 N 件（购买决策） ❤️ N 万（口碑决策）
排序逻辑 千人千面 + 转化率最高 千人千面 + 互动率最高
留白 极少（信息密度极高） 较多（呼吸感）
点击进入后 商品详情（直接转化） 笔记沉浸阅读

📦 实现核心 — Sticky Header + 双列流

这是淘宝/京东首页的标准结构：上层是滚动 Banner/金刚区，中部是粘性分类 Tab，下方是双列瀑布流

1️⃣ 整体布局：UICollectionView + Compositional Layout

// 三段式 section - (UICollectionViewLayout *)makeLayout { return [UICollectionViewCompositionalLayout layoutWithSectionProvider:^NSCollectionLayoutSection *(NSInteger sectionIdx, id<NSCollectionLayoutEnvironment> env) { switch (sectionIdx) { case 0: return [self bannerSection]; case 1: return [self quickEntrySection]; // 金刚区 case 2: return [self productGridSection]; // 双列商品 default: return nil; } }]; } // ⭐ 双列商品 section（带 sticky header） - (NSCollectionLayoutSection *)productGridSection { // item: 占一半宽度 NSCollectionLayoutItem *item = [NSCollectionLayoutItem itemWithLayoutSize: [NSCollectionLayoutSize sizeWithWidthDimension: [NSCollectionLayoutDimension fractionalWidthDimension:0.5] heightDimension: [NSCollectionLayoutDimension estimatedDimension:280]]]; item.contentInsets = NSDirectionalEdgeInsetsMake(2, 2, 2, 2); // group: 一行 2 个 NSCollectionLayoutGroup *group = [NSCollectionLayoutGroup horizontalGroupWithLayoutSize: [NSCollectionLayoutSize sizeWithWidthDimension: [NSCollectionLayoutDimension fractionalWidthDimension:1.0] heightDimension: [NSCollectionLayoutDimension estimatedDimension:280]] subitem:item count:2]; NSCollectionLayoutSection *section = [NSCollectionLayoutSection sectionWithGroup:group]; // ⭐ 关键：sticky header（猜你喜欢 / 直播 / 视频 Tab 栏） NSCollectionLayoutBoundarySupplementaryItem *header = [NSCollectionLayoutBoundarySupplementaryItem boundarySupplementaryItemWithLayoutSize: [NSCollectionLayoutSize sizeWithWidthDimension: [NSCollectionLayoutDimension fractionalWidthDimension:1.0] heightDimension: [NSCollectionLayoutDimension absoluteDimension:44]] elementKind:UICollectionElementKindSectionHeader alignment:NSRectAlignmentTop]; header.pinToVisibleBounds = YES; // ⭐ 滚动时贴顶 section.boundarySupplementaryItems = @[header]; return section; }
关键巧思：pinToVisibleBounds = YES
让 section header 在滚出 viewport 时贴顶，是淘宝/京东"猜你喜欢" Tab 永远在顶的实现方式。比自己监听 contentOffset 模拟优雅 100 倍。

2️⃣ 渐变导航栏 — 上滑才显示

// 跟随 contentOffset 渐变（淘宝/京东标准实现） - (void)scrollViewDidScroll:(UIScrollView *)scrollView { CGFloat offset = scrollView.contentOffset.y; CGFloat threshold = 100; // 0~100 之间 alpha 从 0 到 1 CGFloat alpha = MAX(0, MIN(1, offset / threshold)); // ⭐ 用 setBackgroundImage 的 fix 比改 alpha 更稳（NavBar 内部子视图复杂） [self.navigationController.navigationBar setBackgroundImage:[self imageWithColor: [[UIColor systemRedColor] colorWithAlphaComponent:alpha]] forBarMetrics:UIBarMetricsDefault]; }

🎨 视觉权重的对比技巧

淘宝商品卡的视觉层次（从重到轻）：
1. 价格（红色 / 大号 / 加粗）—— 决策核心
2. 主图（占 60% 面积）—— 吸引点击
3. 已售数量（灰色 / 小字）—— 社会证明
4. 标题（黑色 / 中号 / 2 行截断）—— 辅助理解
小红书笔记卡的视觉层次：
1. 图片（占 70%+ 面积）—— 内容本身
2. 标题（黑色 / 中号 / 2 行）—— 内容预览
3. 作者头像 + 名字（小尺寸）—— 关注转化
4. 点赞数（小字 + 心形）—— 社交证据
价格在哪？—— 没有！点进笔记后才出现「商品卡片」，避免商业感破坏内容氛围。

🎓 横向学习总结（可借鉴的设计）

借鉴 1：双列流的 ASPECT RATIO 选择
· 固定比例（淘宝、京东商品图正方形）= 整齐、便于横向对比
· 不固定比例（小红书瀑布）= 内容感、鼓励探索
根据业务目的选：要"对比"用固定，要"沉浸"用瀑布。
借鉴 2：金刚区的"5 个" magic number
淘宝、美团、京东都用 5 个 / 行 × 2 行 = 10 个金刚区入口。手机宽度下 5 个图标视觉舒适，超过 5 个会显得拥挤。
借鉴 3：Sticky Tab 的 Apple 推荐做法
用 UICollectionViewCompositionalLayout + pinToVisibleBounds = YES。比自己监听 contentOffset 切换 view 简洁、性能更好。
借鉴 4：底部"看了又看"
详情页底部接一个相似商品流，用户向下滚到底自然进入下一个商品。淘宝、亚马逊、京东都用，能让用户停留时长 +40%。
借鉴 5：双击商品图 = 收藏
Instagram 发明、TikTok 沿用、淘宝也加了。「从不教用户的隐藏快捷操作」让重度用户感到"懂行"，是产品归属感的来源。
