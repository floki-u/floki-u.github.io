🧠 核心算法 —— "最短列优先"

瀑布流的核心算法只有一句：
每个新 item 都放进当前最矮的那一列。这样能保证整体视觉平衡，不会出现某一列特别长。

逐步演示（2 列瀑布流）：

初始状态：[ 0, 0 ] // 两列高度都是 0 放 item0 (h=120) → 找最短列(0) → 放第 0 列 状态：[ 120, 0 ] ┌─────┬─────┐ │ #0 │ │ └─────┘ ├─────┐ 放 item1 (h=180) → 找最短列(1) → 放第 1 列 状态：[ 120, 180 ] ┌─────┬─────┐ │ #0 │ #1 │ └─────┤ │ │ │ └─────┘ 放 item2 (h=140) → 找最短列(0) → 放第 0 列 状态：[ 260, 180 ] ┌─────┬─────┐ │ #0 │ #1 │ ├─────┤ │ │ #2 │ │ │ ├─────┤ └─────┘ 放 item3 (h=200) → 找最短列(1) → 放第 1 列 状态：[ 260, 380 ] ...

📦 完整代码 —— WaterfallLayout

继承 UICollectionViewLayout，重写 4 个核心方法

1️⃣ 接口设计

// WaterfallLayout.h @protocol WaterfallLayoutDelegate <NSObject> // ⭐ 把"每个 item 高度"的决策权交给业务方（通常 ViewModel 已经预算好） - (CGFloat)waterfallLayout:(WaterfallLayout *)layout heightForItemAtIndexPath:(NSIndexPath *)indexPath itemWidth:(CGFloat)itemWidth; @end @interface WaterfallLayout : UICollectionViewLayout @property (nonatomic, assign) NSInteger columnCount; // 列数 @property (nonatomic, assign) CGFloat columnSpacing; // 列间距 @property (nonatomic, assign) CGFloat itemSpacing; // 行间距 @property (nonatomic, assign) UIEdgeInsets sectionInset; @property (nonatomic, weak) id<WaterfallLayoutDelegate> delegate; @end

2️⃣ 核心：prepareLayout —— 预计算所有 item 位置

@implementation WaterfallLayout { NSMutableArray<UICollectionViewLayoutAttributes *> *_attrsCache; // item 属性缓存 NSMutableArray<NSNumber *> *_columnHeights; // 每列当前高度 CGFloat _contentHeight; } - (void)prepareLayout { [super prepareLayout]; // ⭐ 1. 重置缓存 _attrsCache = [NSMutableArray array]; _columnHeights = [NSMutableArray arrayWithCapacity:self.columnCount]; for (NSInteger i = 0; i < self.columnCount; i++) { [_columnHeights addObject:@(self.sectionInset.top)]; } _contentHeight = 0; // ⭐ 2. 算每列宽度 CGFloat totalSpacing = self.sectionInset.left + self.sectionInset.right + (self.columnCount - 1) * self.columnSpacing; CGFloat itemWidth = (self.collectionView.bounds.size.width - totalSpacing) / self.columnCount; // ⭐ 3. 遍历所有 item，决定放哪一列 NSInteger itemCount = [self.collectionView numberOfItemsInSection:0]; for (NSInteger i = 0; i < itemCount; i++) { NSIndexPath *ip = [NSIndexPath indexPathForItem:i inSection:0]; // 问 delegate 这个 item 多高 CGFloat itemHeight = [self.delegate waterfallLayout:self heightForItemAtIndexPath:ip itemWidth:itemWidth]; // ⭐⭐⭐ 核心：找最短列 NSInteger shortestCol = 0; CGFloat minHeight = _columnHeights[0].CGFloatValue; for (NSInteger c = 1; c < self.columnCount; c++) { if (_columnHeights[c].CGFloatValue < minHeight) { minHeight = _columnHeights[c].CGFloatValue; shortestCol = c; } } // ⭐ 算 item 的 frame CGFloat x = self.sectionInset.left + shortestCol * (itemWidth + self.columnSpacing); CGFloat y = minHeight; UICollectionViewLayoutAttributes *attrs = [UICollectionViewLayoutAttributes layoutAttributesForCellWithIndexPath:ip]; attrs.frame = CGRectMake(x, y, itemWidth, itemHeight); [_attrsCache addObject:attrs]; // 更新该列高度 _columnHeights[shortestCol] = @(y + itemHeight + self.itemSpacing); } // ⭐ 4. 算总高度（用最高那一列） for (NSNumber *h in _columnHeights) { _contentHeight = MAX(_contentHeight, h.CGFloatValue); } _contentHeight += self.sectionInset.bottom; }

3️⃣ 必须实现的 3 个查询方法

// ⭐ contentSize：告诉 collectionView 总滚动范围 - (CGSize)collectionViewContentSize { return CGSizeMake(self.collectionView.bounds.size.width, _contentHeight); } // ⭐ 给定一个区域，返回所有可见 item 的属性（性能关键） - (NSArray<UICollectionViewLayoutAttributes *> *)layoutAttributesForElementsInRect:(CGRect)rect { // ⚠️ 注意：这个方法每次滚动都被调用，必须高效 // 简单实现：遍历缓存，过滤相交的 NSMutableArray *result = [NSMutableArray array]; for (UICollectionViewLayoutAttributes *attrs in _attrsCache) { if (CGRectIntersectsRect(attrs.frame, rect)) { [result addObject:attrs]; } } return result; // ⭐ 高级优化：用二分查找快速定位区间，O(logN) } // ⭐ 单个 item 属性 - (UICollectionViewLayoutAttributes *)layoutAttributesForItemAtIndexPath:(NSIndexPath *)ip { return _attrsCache[ip.item]; } // ⭐ bounds 变化时是否重新布局（旋转、宽度变化要重算） - (BOOL)shouldInvalidateLayoutForBoundsChange:(CGRect)newBounds { return newBounds.size.width != self.collectionView.bounds.size.width; } @end

4️⃣ 业务侧使用

@implementation DiscoverViewController - (void)viewDidLoad { WaterfallLayout *layout = [[WaterfallLayout alloc] init]; layout.columnCount = 2; layout.columnSpacing = 8; layout.itemSpacing = 8; layout.sectionInset = UIEdgeInsetsMake(8, 8, 8, 8); layout.delegate = self; self.collectionView = [[UICollectionView alloc] initWithFrame:self.view.bounds collectionViewLayout:layout]; } // 实现 delegate - (CGFloat)waterfallLayout:(WaterfallLayout *)layout heightForItemAtIndexPath:(NSIndexPath *)ip itemWidth:(CGFloat)itemWidth { PinModel *pin = self.pins[ip.item]; // ⭐ 关键：图片高度按宽高比缩放，文本高度提前预算 CGFloat imageHeight = itemWidth * pin.imageAspectRatio; CGFloat textHeight = pin.titleHeight; // ViewModel 子线程预算 return imageHeight + textHeight + 16; } @end

🚀 高级优化：二分查找加速 layoutAttributesForElementsInRect

问题： 1 万个 item 时，每次滚动都遍历整个缓存判断相交，O(N) 太慢。
// 假设 _attrsCache 按 frame.minY 升序排列（瀑布流不严格，但近似有序） - (NSInteger)binarySearchFirstIndexInRect:(CGRect)rect { NSInteger low = 0, high = _attrsCache.count - 1; while (low <= high) { NSInteger mid = (low + high) / 2; CGRect midFrame = _attrsCache[mid].frame; if (CGRectGetMaxY(midFrame) < CGRectGetMinY(rect)) { low = mid + 1; } else { high = mid - 1; } } return low; } - (NSArray *)layoutAttributesForElementsInRect:(CGRect)rect { NSInteger startIdx = [self binarySearchFirstIndexInRect:rect]; NSMutableArray *result = [NSMutableArray array]; for (NSInteger i = startIdx; i < _attrsCache.count; i++) { UICollectionViewLayoutAttributes *attrs = _attrsCache[i]; if (CGRectGetMinY(attrs.frame) > CGRectGetMaxY(rect)) break; if (CGRectIntersectsRect(attrs.frame, rect)) [result addObject:attrs]; } return result; }
O(N) → O(log N + K)，K 是可见 item 数。1 万 item 滚动也丝滑。

⚖️ 反例 vs 正例

❌ 反例：在 cellForItem 里算高度

- (UICollectionViewCell *)collectionView:...{ // ❌ 主线程 boundingRectWithSize CGSize size = [pin.title boundingRectWithSize:... options:...].size; cell.titleLabel.frame = CGRectMake(0,0,size.width,size.height); } // 滚动时每个 cell 都算一次，必卡

✅ 正例：ViewModel 子线程预算

- (void)parsePinList:(NSArray *)json { // ⭐ 拉到数据立刻在子线程算高度 dispatch_async(bgQueue, ^{ for (PinModel *p in models) { p.titleHeight = [self heightOfText:p.title width:itemWidth]; } dispatch_async(dispatch_get_main_queue(), ^{ [self.cv reloadData]; }); }); }

⚠️ 实战易错点

坑 1：prepareLayout 里调 numberOfItems 死循环
在 prepare 里调 collectionView numberOfItemsInSection: 是安全的，但如果你在 dataSource 里也触发 layout 操作，会陷入死循环。
坑 2：忘记 invalidateLayout
数据变化后必须 [layout invalidateLayout] 或 [cv reloadData]，否则 prepareLayout 不会重跑。
坑 3：列宽是浮点数导致缝隙
(总宽 - 边距) / 列数 可能不是整数，渲染后列与列间会有 1px 缝。
解决：用 floor 取整，剩余像素加到 sectionInset.right。
最佳实践：用开源库
生产可直接用 CHTCollectionViewWaterfallLayout 或 Swift 的 WaterfallGrid。原理一致，但已处理了大量边界 case。
