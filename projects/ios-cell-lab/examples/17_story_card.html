关键设计：彩环渐变 vs 灰环
· 彩环（橙→粉→紫）：Instagram 标志性配色，表示"有未读 Story"
· 灰环：表示"已读"
这一个圆环颜色变化，让用户在 1 秒内识别"哪些朋友有新内容"，是极致效率的视觉编码。

触控分区（鼠标悬停查看）：
· 左侧 1/4：上一个 Story / 上一个用户
· 中间 1/2：长按暂停（看清细节）
· 右侧 1/4：下一个 Story / 下一个用户
· 下滑：关闭 Story 进入下一层级
· 左/右 滑：切换用户（不是 Story）

🧠 Story 模式的设计精髓

设计原因
限时 24 小时 降低发布心理负担（不会"留下黑历史"），提升发布频率
满屏沉浸 消除信息焦虑（不让用户看见"还有多少没看完"）
顶部分段进度条 用最小视觉成本告诉用户"这一组有几条 / 当前到哪一条"
5-7 秒自动推进 符合短内容的注意力时长，比短视频更短促
点击切换 vs 滑动切换分层级 点击 = Story 内切换；滑动 = 用户间切换。两个交互绝不混淆
下滑关闭 对应"上拉打开"的对称操作，符合手势心智模型
看完不留痕 看了就消失，不像 Feed 还能翻回来。降低浏览压力

📦 核心实现 — 进度条 + 自动推进

1️⃣ 渐变圆环头像（StoryRingView）

@implementation StoryRingView { CAGradientLayer *_ringLayer; UIImageView *_avatarView; } - (instancetype)initWithFrame:(CGRect)frame { if (self = [super initWithFrame:frame]) { // ⭐ 渐变彩环（Instagram 同款配色） _ringLayer = [CAGradientLayer layer]; _ringLayer.colors = @[ (id)[UIColor colorWithRed:0.94 green:0.58 blue:0.20 alpha:1].CGColor, // 橙 (id)[UIColor colorWithRed:0.86 green:0.15 blue:0.40 alpha:1].CGColor, // 红 (id)[UIColor colorWithRed:0.74 green:0.10 blue:0.53 alpha:1].CGColor, // 紫 ]; _ringLayer.startPoint = CGPointMake(0, 0); _ringLayer.endPoint = CGPointMake(1, 1); // ⭐ 用 mask 把矩形渐变变成圆环 CAShapeLayer *mask = [CAShapeLayer layer]; mask.fillColor = [UIColor clearColor].CGColor; mask.strokeColor = [UIColor blackColor].CGColor; mask.lineWidth = 3; mask.path = [UIBezierPath bezierPathWithOvalInRect: CGRectInset(self.bounds, 2, 2)].CGPath; _ringLayer.mask = mask; _ringLayer.frame = self.bounds; [self.layer addSublayer:_ringLayer]; // 头像 _avatarView = [[UIImageView alloc] initWithFrame:CGRectInset(self.bounds, 6, 6)]; _avatarView.layer.cornerRadius = (self.bounds.size.width - 12) / 2; _avatarView.layer.masksToBounds = YES; [self addSubview:_avatarView]; } return self; } - (void)setViewed:(BOOL)viewed { // ⭐ 已读时把彩环变灰 _ringLayer.colors = viewed ? @[ (id)[UIColor lightGrayColor].CGColor, (id)[UIColor lightGrayColor].CGColor, ] : self.gradientColors; } @end

2️⃣ 进度条 + CADisplayLink 同步

@implementation StoryProgressView { NSMutableArray<UIView *> *_segments; NSMutableArray<UIView *> *_fills; NSInteger _currentIndex; CADisplayLink *_link; CFTimeInterval _startTime; CGFloat _duration; // 单段时长（图片 5s / 视频 = 视频时长） } - (void)setupWithSegmentCount:(NSInteger)count { _segments = [NSMutableArray array]; _fills = [NSMutableArray array]; for (NSInteger i = 0; i < count; i++) { UIView *seg = [[UIView alloc] init]; seg.backgroundColor = [[UIColor whiteColor] colorWithAlphaComponent:0.3]; seg.layer.cornerRadius = 1.25; [self addSubview:seg]; [_segments addObject:seg]; UIView *fill = [[UIView alloc] init]; fill.backgroundColor = [UIColor whiteColor]; fill.frame = CGRectMake(0, 0, 0, 0); // 宽度 0，按进度展开 [seg addSubview:fill]; [_fills addObject:fill]; } } - (void)startSegment:(NSInteger)idx duration:(CGFloat)duration { _currentIndex = idx; _duration = duration; _startTime = CACurrentMediaTime(); // 之前的 segment 设为满 for (NSInteger i = 0; i < idx; i++) { _fills[i].frame = _segments[i].bounds; } // 之后的 segment 设为空 for (NSInteger i = idx + 1; i < _segments.count; i++) { _fills[i].frame = CGRectZero; } // ⭐ 用 CADisplayLink 每帧更新当前 segment 宽度（60fps 流畅） [_link invalidate]; _link = [CADisplayLink displayLinkWithTarget:self selector:@selector(tick)]; [_link addToRunLoop:[NSRunLoop mainRunLoop] forMode:NSRunLoopCommonModes]; } - (void)tick { CFTimeInterval elapsed = CACurrentMediaTime() - _startTime; CGFloat progress = MIN(1.0, elapsed / _duration); UIView *seg = _segments[_currentIndex]; UIView *fill = _fills[_currentIndex]; fill.frame = CGRectMake(0, 0, seg.bounds.size.width * progress, seg.bounds.size.height); if (progress >= 1.0) { [_link invalidate]; if (self.onSegmentComplete) self.onSegmentComplete(_currentIndex); } } - (void)pause { _link.paused = YES; } - (void)resume { // ⭐ resume 时调整 _startTime，否则会跳到结尾 UIView *fill = _fills[_currentIndex]; CGFloat currentProgress = fill.frame.size.width / _segments[_currentIndex].bounds.size.width; _startTime = CACurrentMediaTime() - _duration * currentProgress; _link.paused = NO; } @end

3️⃣ 触控分区

- (void)handleTap:(UITapGestureRecognizer *)tap { CGPoint p = [tap locationInView:self.view]; CGFloat w = self.view.bounds.size.width; if (p.x < w * 0.3) { [self previousStory]; } else if (p.x > w * 0.7) { [self nextStory]; } } - (void)handleLongPress:(UILongPressGestureRecognizer *)lp { if (lp.state == UIGestureRecognizerStateBegan) { [self.progressView pause]; [self.player pause]; // ⭐ 长按时隐藏 UI（让用户看清内容） [UIView animateWithDuration:0.2 animations:^{ self.headerView.alpha = 0; self.progressView.alpha = 0; self.inputBar.alpha = 0; }]; } else if (lp.state == UIGestureRecognizerStateEnded) { [self.progressView resume]; [self.player play]; [UIView animateWithDuration:0.2 animations:^{ self.headerView.alpha = 1; self.progressView.alpha = 1; self.inputBar.alpha = 1; }]; } }

🎓 可借鉴的创新点

借鉴 1：分段进度条作为"目录"
不只是显示进度，还告诉用户"这一组有几条"。用户决定要不要继续看。
可推广到任何"序列内容"场景：教学课程、新手引导、产品介绍。
借鉴 2：长按隐藏 UI
给用户"看清细节"的能力。视频/图片浏览类 App 都该有。
借鉴 3：彩环 → 灰环的状态编码
用颜色 + 形状双重编码已读未读，比单纯红点更清晰。
借鉴 4：左右分屏触控
手机大屏时代，左右大拇指各管一半屏幕，比"必须按某个按钮"更人性化。
Kindle 翻页、Pocket 阅读、抖音也借用这套。
借鉴 5：下滑关闭手势的"接力"
Story 关闭后回到 Feed，动画上是头像缩小回到圆环位置。这种"来源即去向"的转场，让 App 有了"空间感"。
iOS 的 UIViewControllerTransitioningDelegate 可以实现，参考 Apple 的 Interactive Transitions 文档。
