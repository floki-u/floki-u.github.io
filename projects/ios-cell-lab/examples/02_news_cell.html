2️⃣ NewsCell（新闻卡片：阴影 + 圆角）

新闻卡片是阴影 + 圆角组合的典型场景。看似简单，但 80% 的人写错 —— 要么阴影被裁掉，要么 FPS 被离屏渲染拖垮。本节讲正确的"分层"结构。

🤔 核心难题：为什么阴影 + 圆角这么难？

A
想用 cornerRadius + clipsToBounds 实现圆角卡片 → 触发离屏渲染
B
想给卡片加阴影 → shadowColor + shadowOpacity 的同时必须 clipsToBounds = NO， 否则阴影会被裁掉
C
但圆角又需要 clipsToBounds 来裁内部图片
→ 矛盾：要圆角就要裁，要阴影就不能裁
💡 解法： 分两层！外层 cardView 负责阴影（不 clip）， 内层负责裁圆角内容。封面图自己用 maskedCorners + clipsToBounds 裁上面两个角。

🧱 正确的 layer 分层结构

这个结构是新闻/商品/消息卡片的"通用解法"，背下来一辈子受用
contentView // 灰色背景 └─ cardView ⭐ 带阴影 + 圆角，但不 clip ├─ coverView 封面图，maskedCorners 只圆上面两角 ├─ titleLabel opaque 不透明 ├─ tagLabel cornerCurve.continuous，不 clip └─ metaLabel opaque 不透明
⚠️ 关键约束： cardView 不能 clipsToBounds = YES，否则它的 shadow 会被自身裁掉看不见。 圆角的"裁内容"动作要交给它的子 view（比如 coverView）自己负责。

✅ 关键 1：阴影必须显式 shadowPath

不设 shadowPath，每帧都要按 alpha 通道推算阴影形状 = 离屏渲染
❌ 反例：阴影不设 path
card.layer.shadowColor =
  [UIColor blackColor].CGColor;
card.layer.shadowOpacity = 0.08;
card.layer.shadowOffset =
  CGSizeMake(0, 2);
card.layer.shadowRadius = 8;

// ❌ 没设 shadowPath
// → GPU 每帧都要按 alpha
//   通道推算阴影形状
// → Color Off-screen Rendered
//   全卡片黄色
✅ 正例：显式 shadowPath
card.layer.shadowColor =
  [UIColor blackColor].CGColor;
card.layer.shadowOpacity = 0.08;
card.layer.shadowOffset =
  CGSizeMake(0, 2);
card.layer.shadowRadius = 8;

// ⭐ 在 layoutSubviews 里更新
- (void)layoutSubviews {
  [super layoutSubviews];
  card.layer.shadowPath =
    [UIBezierPath
      bezierPathWithRoundedRect:
        card.bounds
      cornerRadius:12].CGPath;
}
📖 原理： 系统画阴影需要先知道"被投影物体的形状"。如果不告诉它，它就要每帧扫描 alpha 通道推算， 极其耗 GPU。shadowPath 就是直接把形状告诉它，省去推算。

✅ 关键 2：圆角用 cornerCurve，不加 clipsToBounds

iOS 13+ 的 cornerCurve = .continuous 是丝滑圆角的最优解
❌ 反例：cornerRadius + clipsToBounds
card.layer.cornerRadius = 12;
card.clipsToBounds = YES;

// ❌ 1. 触发离屏渲染
// ❌ 2. 阴影会被裁掉看不见
// ❌ 3. iOS 标准矩形圆角，
//      不如 macOS 那种"超椭圆"丝滑
✅ 正例：cornerCurve.continuous
card.layer.cornerRadius = 12;
card.layer.cornerCurve =
  kCACornerCurveContinuous;  // iOS 13+
// ⭐ 不加 clipsToBounds

// ✅ 1. 不触发离屏（iOS 11+ 起优化）
// ✅ 2. 阴影不会被裁
// ✅ 3. "超椭圆"圆角更丝滑
💡 cornerCurve 是什么： Apple 在 iOS 13 引入的"连续曲率"圆角，转角处更平滑（macOS 风格）。 视觉对比：标准圆角是"圆弧 + 直线"硬接，连续圆角是"逐渐过渡"，更高级。

✅ 关键 3：封面图用 maskedCorners 实现部分圆角

封面图只圆上面两个角（贴合卡片形状），用 maskedCorners 而不是 mask
_coverView = [[UIImageView alloc] init];
_coverView.contentMode = UIViewContentModeScaleAspectFill;
_coverView.opaque = YES;
_coverView.layer.cornerRadius = 12;
_coverView.layer.cornerCurve = kCACornerCurveContinuous;
// ⭐ 只圆上面两个角
_coverView.layer.maskedCorners =
  kCALayerMinXMinYCorner | kCALayerMaxXMinYCorner;
// ⚠️ 这里必须 clipsToBounds 才能裁掉超出圆角的图片
// 这里会有少量离屏，但单图片裁切代价小，可接受
_coverView.clipsToBounds = YES;
📂 进阶：完全消除封面图离屏的方案

如果你对性能要求极致，可以让 SDWebImage 在解码时一并切好圆角， UIImageView 就不需要 clipsToBounds 了 → 完全 0 离屏。 

SDWebImageRoundCornerTransformer *t =
  [[SDWebImageRoundCornerTransformer alloc]
    initWithRadius:12
           corners:UIRectCornerTopLeft | UIRectCornerTopRight
       borderWidth:0 borderColor:nil];

[coverView sd_setImageWithURL:url
        placeholderImage:nil
                 options:0
                 context:@{SDWebImageContextImageTransformer: t}];

// ✅ 切好的图本身就是部分圆角的
coverView.clipsToBounds = NO;  // 不需要裁了

📦 完整 NewsCell.m 实现

@interface NewsCell ()
@property (nonatomic, strong) UIView *cardView;        // 阴影层
@property (nonatomic, strong) UIImageView *coverView;
@property (nonatomic, strong) UILabel *titleLabel;
@property (nonatomic, strong) UILabel *tagLabel;
@property (nonatomic, strong) UILabel *metaLabel;
@end

@implementation NewsCell

- (instancetype)initWithStyle:... {
  if (self = [super ...]) {
    self.contentView.backgroundColor =
      [UIColor colorWithWhite:0.95 alpha:1];
    self.contentView.opaque = YES;

    // ⭐ 外层 cardView：负责阴影 + 圆角，但不 clip
    _cardView = [[UIView alloc] init];
    _cardView.backgroundColor = [UIColor whiteColor];
    _cardView.opaque = YES;
    _cardView.layer.cornerRadius = 12;
    _cardView.layer.cornerCurve = kCACornerCurveContinuous;
    // 阴影 ✅ 必须显式 shadowPath
    _cardView.layer.shadowColor = [UIColor blackColor].CGColor;
    _cardView.layer.shadowOpacity = 0.08;
    _cardView.layer.shadowOffset = CGSizeMake(0, 2);
    _cardView.layer.shadowRadius = 8;
    // shadowPath 在 layoutSubviews 里更新
    [self.contentView addSubview:_cardView];

    // 封面图：只圆上面两个角
    _coverView = [[UIImageView alloc] init];
    _coverView.contentMode = UIViewContentModeScaleAspectFill;
    _coverView.opaque = YES;
    _coverView.layer.cornerRadius = 12;
    _coverView.layer.cornerCurve = kCACornerCurveContinuous;
    _coverView.layer.maskedCorners =
      kCALayerMinXMinYCorner | kCALayerMaxXMinYCorner;
    _coverView.clipsToBounds = YES;
    [_cardView addSubview:_coverView];

    // 标签
    _titleLabel = ...; _titleLabel.numberOfLines = 2;
    _tagLabel = ...; _tagLabel.layer.cornerRadius = 4;
    _tagLabel.layer.cornerCurve = kCACornerCurveContinuous;
    // ✅ 不加 clipsToBounds
    _metaLabel = ...;
  }
  return self;
}

// ⭐ 关键：每次 frame 变化都要更新 shadowPath
- (void)layoutSubviews {
  [super layoutSubviews];
  if (!CGRectIsEmpty(self.cardView.bounds)) {
    self.cardView.layer.shadowPath =
      [UIBezierPath
        bezierPathWithRoundedRect:self.cardView.bounds
        cornerRadius:12].CGPath;
  }
}

- (void)prepareForReuse {
  [super prepareForReuse];
  [self.coverView sd_cancelCurrentImageLoad];
  self.coverView.image = nil;
  self.titleLabel.text = nil;
  self.tagLabel.text = nil;
  self.metaLabel.text = nil;
}

- (void)configureWithViewModel:(NewsViewModel *)vm {
  self.cardView.frame = vm.cardFrame;
  self.coverView.frame = vm.coverFrame;
  // ... 其他 frame

  self.titleLabel.text = vm.news.title;
  self.tagLabel.text = vm.news.tag;
  self.metaLabel.text = vm.metaText;

  [self.coverView sd_setImageWithURL:vm.news.coverURL];
}

@end

⚠️ 易错点

坑 1： 给 cardView 加了 clipsToBounds = YES → shadow 会被裁没看不见。永远不要给"带阴影的 view"开 clip。
坑 2： shadowPath 不在 layoutSubviews 里更新 → frame 变化后阴影位置/形状不对。横竖屏切换、cell 复用尺寸变化时都会出问题。
坑 3： cardView 里只用 cornerRadius 不设 cornerCurve → 视觉上是 iOS 老式圆角，不够丝滑。iOS 13+ 都加上 cornerCurve.continuous。
提示： 如果 deployment target ≥ iOS 13，cornerCurve.continuous 闭着眼睛加，没有任何副作用。
