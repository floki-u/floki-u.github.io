🚨 为什么需要骨架屏？

传统菊花的问题：
1. 用户不知道"加载多久"，体感焦虑
2. 加载完成后整个页面"突然出现"，视觉跳变
3. 没有空间预占，layout 会跳动（CLS - Cumulative Layout Shift）
骨架屏的优势：
1. 预先占位 —— 用户立刻看到布局，知道"内容会出现在哪里"
2. 感知加速 —— Shimmer 流光暗示"正在加载"，主观加载时间 ↓ 30%（Facebook 数据）
3. 无 layout 跳变 —— 骨架尺寸 ≈ 真实 cell 尺寸

📦 完整代码实现

用 CAGradientLayer + CABasicAnimation 实现 Shimmer，性能远高于切图序列帧

1️⃣ SkeletonView.h —— 通用骨架视图

// SkeletonView.h —— 一块带 Shimmer 动画的灰色占位 @interface SkeletonView : UIView - (void)startShimmering; - (void)stopShimmering; @end

2️⃣ SkeletonView.m —— Shimmer 核心实现

@implementation SkeletonView { CAGradientLayer *_gradientLayer; } - (instancetype)initWithFrame:(CGRect)frame { if (self = [super initWithFrame:frame]) { self.backgroundColor = [UIColor colorWithRed:0.92 green:0.93 blue:0.95 alpha:1]; self.layer.cornerRadius = 6; self.layer.masksToBounds = YES; // 让渐变被圆角裁剪 // ⭐ 关键：用 CAGradientLayer 做 shimmer，比 image 序列帧高效 _gradientLayer = [CAGradientLayer layer]; _gradientLayer.colors = @[ (id)[UIColor clearColor].CGColor, (id)[[UIColor whiteColor] colorWithAlphaComponent:0.5].CGColor, (id)[UIColor clearColor].CGColor ]; _gradientLayer.startPoint = CGPointMake(0, 0.5); _gradientLayer.endPoint = CGPointMake(1, 0.5); _gradientLayer.locations = @[@0, @0.5, @1]; [self.layer addSublayer:_gradientLayer]; } return self; } - (void)layoutSubviews { [super layoutSubviews]; // 让渐变宽度 = 自身宽度的 3 倍，左右各一倍可滑出 _gradientLayer.frame = CGRectMake(-self.bounds.size.width, 0, self.bounds.size.width * 3, self.bounds.size.height); } - (void)startShimmering { // ⭐ 用 CABasicAnimation 推 transform.translation.x，GPU 直接处理，几乎零 CPU CABasicAnimation *anim = [CABasicAnimation animationWithKeyPath:@"transform.translation.x"]; anim.fromValue = @0; anim.toValue = @(self.bounds.size.width * 2); anim.duration = 1.4; anim.repeatCount = HUGE_VALF; anim.timingFunction = [CAMediaTimingFunction functionWithName:kCAMediaTimingFunctionEaseInOut]; [_gradientLayer addAnimation:anim forKey:@"shimmer"]; } - (void)stopShimmering { [_gradientLayer removeAnimationForKey:@"shimmer"]; } @end
为什么用 CAGradientLayer + CABasicAnimation：
· 纯 GPU 操作：渐变绘制和位移动画都走 GPU，不占主线程
· 没有图片资源：相比序列帧 PNG，包体积 0 增长
· 自适应宽度：layoutSubviews 自动重算，旋转/分屏都不用管
· 批量低成本：100 个骨架 cell 同时跑动画，CPU < 2%

3️⃣ SkeletonMessageCell.m —— 消息列表骨架 cell

@interface SkeletonMessageCell : UITableViewCell @end @implementation SkeletonMessageCell { SkeletonView *_avatarSkel; SkeletonView *_titleSkel; SkeletonView *_subtitleSkel; } - (instancetype)initWithStyle:(UITableViewCellStyle)style reuseIdentifier:(NSString *)reuseIdentifier { if (self = [super initWithStyle:style reuseIdentifier:reuseIdentifier]) { self.selectionStyle = UITableViewCellSelectionStyleNone; self.contentView.backgroundColor = [UIColor whiteColor]; _avatarSkel = [[SkeletonView alloc] init]; _avatarSkel.layer.cornerRadius = 24; // 圆头像 [self.contentView addSubview:_avatarSkel]; _titleSkel = [[SkeletonView alloc] init]; _subtitleSkel = [[SkeletonView alloc] init]; [self.contentView addSubview:_titleSkel]; [self.contentView addSubview:_subtitleSkel]; } return self; } - (void)layoutSubviews { [super layoutSubviews]; _avatarSkel.frame = CGRectMake(16, 14, 48, 48); _titleSkel.frame = CGRectMake(76, 22, 180, 12); _subtitleSkel.frame = CGRectMake(76, 42, 120, 10); } // ⭐ willMove 而不是 didMove，避免动画启动后立刻被 layout 打断 - (void)willMoveToWindow:(UIWindow *)newWindow { [super willMoveToWindow:newWindow]; if (newWindow) { [_avatarSkel startShimmering]; [_titleSkel startShimmering]; [_subtitleSkel startShimmering]; } else { [_avatarSkel stopShimmering]; // 离屏停动画，省电 [_titleSkel stopShimmering]; [_subtitleSkel stopShimmering]; } } @end

4️⃣ ViewController.m —— 状态切换

@implementation MessageListViewController { BOOL _isLoading; NSArray *_messages; } - (void)viewDidLoad { [super viewDidLoad]; [self.tableView registerClass:[SkeletonMessageCell class] forCellReuseIdentifier:@"skel"]; [self.tableView registerClass:[RealMessageCell class] forCellReuseIdentifier:@"real"]; _isLoading = YES; [self loadData]; } - (void)loadData { [API fetchMessagesWithCompletion:^(NSArray *list) { self->_messages = list; self->_isLoading = NO; // ⭐ 用 reloadSections 而不是 reloadData，能带 fade 动画 [self.tableView reloadSections:[NSIndexSet indexSetWithIndex:0] withRowAnimation:UITableViewRowAnimationFade]; }]; } - (NSInteger)tableView:(UITableView *)tv numberOfRowsInSection:(NSInteger)s { return _isLoading ? 8 : _messages.count; // loading 时显示 8 个骨架 } - (UITableViewCell *)tableView:(UITableView *)tv cellForRowAtIndexPath:(NSIndexPath *)ip { if (_isLoading) { return [tv dequeueReusableCellWithIdentifier:@"skel" forIndexPath:ip]; } RealMessageCell *cell = [tv dequeueReusableCellWithIdentifier:@"real" forIndexPath:ip]; [cell configureWithMessage:_messages[ip.row]]; return cell; } @end

⚖️ 反例 vs 正例

❌ 反例：菊花 + reloadData

- (void)viewDidLoad { [self.activityIndicator startAnimating]; [API fetchMessages:^(NSArray *list) { self->_messages = list; [self.activityIndicator stopAnimating]; [self.tableView reloadData]; // ❌ 整页突然出现，视觉跳变 }]; }
用户体感：「白屏 → 菊花 → 突然刷出来一片东西」

✅ 正例：骨架 + fade 动画

- (void)viewDidLoad { _isLoading = YES; [self.tableView reloadData]; // 显示骨架 [API fetchMessages:^(NSArray *list) { _messages = list; _isLoading = NO; [self.tableView reloadSections:... withRowAnimation:UITableViewRowAnimationFade]; }]; }
用户体感：「立刻看到布局 → Shimmer 流光 → 平滑淡入真数据」

⚠️ 实战易错点

坑 1：忘记停动画
离屏 cell 不停 shimmer，会持续占用 GPU。一定要在 willMoveToWindow:nil 或 prepareForReuse 里 stopShimmering。
坑 2：骨架尺寸 ≠ 真实尺寸
骨架高度必须和 loaded 后的 cell 高度一致，否则切换时 tableView 还是会跳。多文案场景可以用 1~2 行的固定骨架兜底。
坑 3：用 UIView 动画做 shimmer
[UIView animateWithDuration] 走主线程，100 个 cell 同时动画必卡。必须用 CAAnimation。
最佳实践：开源库 SkeletonView
生产项目可直接用 SkeletonView (Swift) 或 SDWebImage 自带 placeholder。原理和这里一致。
