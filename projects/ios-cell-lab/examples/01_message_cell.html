🚨 三大经典坑（必看）

这几个问题如果不处理，线上 bug 接踵而至
1
头像错乱：A 头像下载慢，cell 滚走被 B 复用，A 的下载完成回调还在执行 → B 的 cell 突然闪过 A 的头像
2
未读红点不消失：有红点的 cell 滚走后被一个"已读"消息复用， configureWith 里 if (unread > 0) 走不进，红点继续显示
3
头像 cornerRadius + clipsToBounds 触发离屏： 每帧都要做一次离屏渲染，列表滚动 FPS 直线下降

✅ 解决方案 1：prepareForReuse 重置状态

解决坑 1 + 坑 2 —— cell 复用前自动重置所有"会残留"的状态
📖 原理： cell 被复用时，系统会自动调用 prepareForReuse，调用时机在 cellForRowAtIndexPath: 之前。这是清理上一次状态的唯一正确时机。
❌ 反例：没写 prepareForReuse
@implementation MessageCell

- (void)configureWithMessage:(Message *)msg {
  self.nameLabel.text = msg.name;

  // 头像异步下载
  [self.avatarView sd_setImageWithURL:msg.avatarURL];

  // 红点
  if (msg.unreadCount > 0) {
    self.badgeView.hidden = NO;
  }
  // ❌ 没有 else
  // 复用时如果新数据 unread=0
  // → 红点不会被隐藏
}

@end
✅ 正例：用 prepareForReuse
@implementation MessageCell

// ⭐ cell 复用前系统自动调用
- (void)prepareForReuse {
  [super prepareForReuse];

  // 1. 取消未完成的异步任务
  [self.avatarView sd_cancelCurrentImageLoad];

  // 2. 清空所有会残留的 UI 状态
  self.avatarView.image = nil;
  self.nameLabel.text = nil;
  self.badgeView.hidden = YES;

  // 3. 停止动画
  [self.indicator stopAnimating];
}

- (void)configureWithMessage:(Message *)msg {
  // 不用写 else 了
  if (msg.unreadCount > 0) {
    self.badgeView.hidden = NO;
  }
}
⚙️ 复用时序： 滚出屏幕的 cell B → 进入复用池 → 新 indexPath 需要 cell → dequeueReusableCell... → 系统调用 [B prepareForReuse] → 你的 cellForRow → configureWith:newData

✅ 解决方案 2：子线程预切圆图（消除离屏）

解决坑 3 —— 头像不再用 cornerRadius，而是图片本身就是圆的
❌ 反例：cornerRadius + clipsToBounds
// ❌ 触发离屏渲染
self.avatarView.layer.cornerRadius = 24;
self.avatarView.clipsToBounds = YES;

// 加载头像
[self.avatarView
  sd_setImageWithURL:url];

// 现象：
// Color Off-screen Rendered
// → 全屏头像位置都是黄色
// → 滚动 FPS 35-40
✅ 正例：子线程切圆图
// avatar 不设任何 cornerRadius

[self.avatarView sd_setImageWithURL:url
  placeholderImage:placeholder
  completed:^(UIImage *img, ...) {
    if (!img) return;

    // ⭐ 子线程切圆图
    dispatch_async(global_queue, ^{
      UIImage *circle =
        [img circleImageWithSize:size];

      dispatch_async(main_queue, ^{
        // ⭐ 防 cell 已被复用
        if ([iv.sd_imageURL isEqual:u]) {
          iv.image = circle;
        }
      });
    });
  }];
📂 展开：完整的圆图工具方法 UIImage+Circle.m 
@implementation UIImage (Circle)

- (UIImage *)circleImageWithSize:(CGSize)size {
  UIGraphicsBeginImageContextWithOptions(size, NO,
    [UIScreen mainScreen].scale);

  // 圆形裁剪路径
  UIBezierPath *path = [UIBezierPath
    bezierPathWithOvalInRect:
    CGRectMake(0, 0, size.width, size.height)];
  [path addClip];

  // 按 aspectFill 算 draw rect，避免变形
  CGFloat scale = MAX(size.width / self.size.width,
                       size.height / self.size.height);
  CGSize drawSize = CGSizeMake(self.size.width * scale,
                                self.size.height * scale);
  CGRect drawRect = CGRectMake(
    (size.width - drawSize.width) * 0.5,
    (size.height - drawSize.height) * 0.5,
    drawSize.width, drawSize.height);
  [self drawInRect:drawRect];

  UIImage *result = UIGraphicsGetImageFromCurrentImageContext();
  UIGraphicsEndImageContext();
  return result;
}

@end

✅ 解决方案 3：红点用预渲染 UIImage

cornerRadius=9 同样会触发离屏，全局只渲染一张红点图复用
@implementation MessageCell

// ⭐ 全局只渲染一次的红点 image
+ (UIImage *)redBadgeImage {
  static UIImage *image;
  static dispatch_once_t once;
  dispatch_once(&once, ^{
    CGSize size = CGSizeMake(18, 18);
    UIGraphicsBeginImageContextWithOptions(size, NO, scale);
    CGContextRef ctx = UIGraphicsGetCurrentContext();
    CGContextSetFillColorWithColor(ctx, [UIColor systemRedColor].CGColor);
    CGContextFillEllipseInRect(ctx, CGRectMake(0, 0, 18, 18));
    image = UIGraphicsGetImageFromCurrentImageContext();
    UIGraphicsEndImageContext();
  });
  return image;
}

- (instancetype)initWithStyle:... {
  if (self = [super ...]) {
    // ⭐ 红点 = UIImageView 贴预渲染图，无 cornerRadius，无离屏
    _badgeView = [[UIImageView alloc] initWithImage:
                  [MessageCell redBadgeImage]];
    _badgeView.backgroundColor = [UIColor whiteColor]; // opaque
    _badgeView.opaque = YES;
  }
  return self;
}

@end
💡 为什么这样最优： 红点的样式是固定不变的（颜色、形状、大小），全局只需要画一次， 所有 cell 共用同一张 UIImage，0 离屏 + 0 内存增长。

📦 完整 MessageCell.m 实现

把上面所有点串起来的最终代码
@interface MessageCell ()
@property (nonatomic, strong) UIImageView *avatarView;
@property (nonatomic, strong) UILabel *nameLabel;
@property (nonatomic, strong) UILabel *timeLabel;
@property (nonatomic, strong) UILabel *msgLabel;
@property (nonatomic, strong) UIImageView *badgeView;
@end

@implementation MessageCell

- (instancetype)initWithStyle:(UITableViewCellStyle)style
                reuseIdentifier:(NSString *)reuseIdentifier {
  if (self = [super initWithStyle:style reuseIdentifier:reuseIdentifier]) {
    // ✅ contentView 不透明
    self.contentView.backgroundColor = [UIColor whiteColor];
    self.contentView.opaque = YES;

    // 头像：不设任何圆角，由预切圆图实现
    _avatarView = [[UIImageView alloc] init];
    _avatarView.backgroundColor = [UIColor colorWithWhite:0.95 alpha:1];
    _avatarView.opaque = YES;
    [self.contentView addSubview:_avatarView];

    // 文字 label 全部 opaque
    _nameLabel = [self _makeLabel:...];
    _timeLabel = [self _makeLabel:...];
    _msgLabel  = [self _makeLabel:...];

    // ⭐ 红点 = 预渲染图
    _badgeView = [[UIImageView alloc] initWithImage:
                  [MessageCell redBadgeImage]];
    _badgeView.opaque = YES;
    [self.contentView addSubview:_badgeView];
  }
  return self;
}

// ⭐ 复用前重置
- (void)prepareForReuse {
  [super prepareForReuse];
  [self.avatarView sd_cancelCurrentImageLoad];
  self.avatarView.image = nil;
  self.nameLabel.text = nil;
  self.timeLabel.text = nil;
  self.msgLabel.text = nil;
  self.badgeView.hidden = YES;
}

- (void)configureWithViewModel:(MessageViewModel *)vm {
  // 用预算好的 frame
  self.avatarView.frame = vm.avatarFrame;
  self.nameLabel.frame = vm.nameFrame;
  self.timeLabel.frame = vm.timeFrame;
  self.msgLabel.frame = vm.msgFrame;
  self.badgeView.frame = vm.badgeFrame;

  self.nameLabel.text = vm.message.senderName;
  self.timeLabel.text = vm.timeString;
  self.msgLabel.text = vm.message.content;
  self.badgeView.hidden = (vm.message.unreadCount == 0);

  // 头像异步加载 + 子线程切圆图
  NSURL *url = vm.message.avatarURL;
  UIImageView *iv = self.avatarView;
  [iv sd_setImageWithURL:url
       placeholderImage:[UIImage imageNamed:@"placeholder"]
       completed:^(UIImage *image, NSError *err, ...) {
    if (!image) return;
    dispatch_async(global_queue, ^{
      UIImage *circle = [image circleImageWithSize:iv.bounds.size];
      dispatch_async(main_queue, ^{
        if ([iv.sd_imageURL isEqual:u]) {
          iv.image = circle;
        }
      });
    });
  }];
}

@end

📐 配套：MessageViewModel（子线程预算高度）

cell 高度不在 heightForRow 现算，而是子线程预算缓存
@interface MessageViewModel : NSObject
@property (nonatomic, strong) Message *message;
@property (nonatomic, assign) CGFloat cachedHeight;  // ⭐ 缓存
@property (nonatomic, assign) CGRect avatarFrame;
@property (nonatomic, assign) CGRect nameFrame;
@property (nonatomic, assign) CGRect timeFrame;
@property (nonatomic, assign) CGRect msgFrame;
@property (nonatomic, assign) CGRect badgeFrame;
@end

@implementation MessageViewModel

- (void)prepareLayoutIfNeeded {
  if (self.cachedHeight > 0) return;  // 已算过

  self.avatarFrame = CGRectMake(12, 12, 48, 48);
  self.nameFrame   = CGRectMake(72, 14, 200, 20);
  self.timeFrame   = CGRectMake(300, 14, 60, 16);
  self.msgFrame    = CGRectMake(72, 38, 240, 20);
  self.badgeFrame  = CGRectMake(350, 36, 18, 18);
  self.cachedHeight = 72;
}

@end

// VC 里：子线程预算后回主线程刷新
- (void)loadMessages {
  dispatch_async(global_queue, ^{
    NSMutableArray *vms = [NSMutableArray array];
    for (Message *msg in messages) {
      MessageViewModel *vm = [[MessageViewModel alloc] init];
      vm.message = msg;
      [vm prepareLayoutIfNeeded];  // ⭐ 子线程算
      [vms addObject:vm];
    }
    dispatch_async(main_queue, ^{
      self.viewModels = vms;
      [self.tableView reloadData];
    });
  });
}

- (CGFloat)tableView:(UITableView *)tv
        heightForRowAtIndexPath:(NSIndexPath *)ip {
  return self.viewModels[ip.row].cachedHeight;  // O(1) 查表
}
