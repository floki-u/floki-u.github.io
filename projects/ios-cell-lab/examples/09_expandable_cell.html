📂 ExpandableCell — 展开/折叠卡片

FAQ、订单详情、设置项常见组件。难点是展开时高度变化要带动画，且不能让 tableView 跳变。iOS 13 起用 Diffable DataSource 做这件事最优雅。

🚨 核心难点

难点 1：高度变化要平滑
cell 高度从 56pt 变到 180pt，UITableView 默认会"跳"。需要 beginUpdates / endUpdates 或 Diffable DataSource 触发动画。
难点 2：折叠时下方 cell 会"被推上来"
如果展开的是屏幕中间的 cell，折叠时下方所有 cell 上移会很突兀。要么不动 contentOffset（默认行为），要么主动 scrollTo。
难点 3：高度计算不能放主线程
展开后的内容如果是富文本，boundingRectWithSize 在主线程算 → 卡顿。需要预算缓存。

📦 实现方案 A：传统 UITableView（兼容 iOS 11+）

用 NSMutableSet 记录展开的 indexPath，在 heightForRow 里返回不同高度

1️⃣ ViewController

@interface FAQViewController () @property (nonatomic, strong) NSArray<FAQItem *> *items; @property (nonatomic, strong) NSMutableSet<NSIndexPath *> *expandedIndexPaths; @property (nonatomic, strong) NSMutableDictionary<NSIndexPath *, NSNumber *> *heightCache; @end @implementation FAQViewController - (void)viewDidLoad { [super viewDidLoad]; self.expandedIndexPaths = [NSMutableSet set]; self.heightCache = [NSMutableDictionary dictionary]; [self.tableView registerClass:[FAQCell class] forCellReuseIdentifier:@"cell"]; } - (CGFloat)tableView:(UITableView *)tv heightForRowAtIndexPath:(NSIndexPath *)ip { if (![self.expandedIndexPaths containsObject:ip]) { return 56; // 折叠态固定高度 } // ⭐ 展开态高度：先查缓存 NSNumber *cached = self.heightCache[ip]; if (cached) return cached.CGFloatValue; // 算一次（这里假设已在 ViewModel 子线程预算好） FAQItem *item = self.items[ip.row]; CGFloat h = 56 + item.contentHeight + 20; self.heightCache[ip] = @(h); return h; } - (void)tableView:(UITableView *)tv didSelectRowAtIndexPath:(NSIndexPath *)ip { [tv deselectRowAtIndexPath:ip animated:YES]; FAQCell *cell = [tv cellForRowAtIndexPath:ip]; BOOL wasExpanded = [self.expandedIndexPaths containsObject:ip]; if (wasExpanded) { [self.expandedIndexPaths removeObject:ip]; } else { [self.expandedIndexPaths addObject:ip]; } // ⭐ 关键：让 tableView 重新计算自己（带动画） [tv beginUpdates]; [cell setExpanded:!wasExpanded animated:YES]; // cell 内部 chevron 旋转动画 [tv endUpdates]; // 可选：展开时滚到能看见 if (!wasExpanded) { [tv scrollToRowAtIndexPath:ip atScrollPosition:UITableViewScrollPositionNone animated:YES]; } } @end

2️⃣ FAQCell —— Chevron 旋转动画

@implementation FAQCell { UIImageView *_chevron; UILabel *_titleLabel; UILabel *_contentLabel; } - (void)setExpanded:(BOOL)expanded animated:(BOOL)animated { // ⭐ chevron 旋转 90 度 void (^anim)(void) = ^{ _chevron.transform = expanded ? CGAffineTransformMakeRotation(M_PI_2) : CGAffineTransformIdentity; _contentLabel.alpha = expanded ? 1 : 0; }; if (animated) { [UIView animateWithDuration:0.3 delay:0 usingSpringWithDamping:0.85 initialSpringVelocity:0 options:0 animations:anim completion:nil]; } else { anim(); } } @end
为什么 beginUpdates / endUpdates 能带动画：
它告诉 UITableView「我要批量更新」，UITableView 会对比新旧高度，对差值做隐式 CALayer 动画。chevron 的旋转动画是 cell 自己启动的，UITableView 的高度变化是系统启动的，两者并行。

📦 实现方案 B：UICollectionView + Diffable（iOS 13+）

用 OutlineSnapshot 实现"父-子"展开，是 Apple 系统设置 App 的同款方案
// 数据结构 —— 一个 Item 包含 children @interface FAQItem : NSObject @property (nonatomic, copy) NSString *title; @property (nonatomic, copy) NSString *content; @property (nonatomic, copy) NSArray<FAQItem *> *children; @end - (void)viewDidLoad { [super viewDidLoad]; // ⭐ 1. 用 List 布局 UICollectionLayoutListConfiguration *cfg = [[UICollectionLayoutListConfiguration alloc] initWithAppearance:UICollectionLayoutListAppearanceInsetGrouped]; UICollectionViewLayout *layout = [UICollectionViewCompositionalLayout layoutWithListConfiguration:cfg]; self.collectionView = [[UICollectionView alloc] initWithFrame:self.view.bounds collectionViewLayout:layout]; [self.view addSubview:self.collectionView]; // ⭐ 2. 注册 cell（系统提供 valueCell / subtitleCell / sidebarCell 等） UICollectionViewCellRegistration *reg = [UICollectionViewCellRegistration registrationWithCellClass:[UICollectionViewListCell class] configurationHandler:^(UICollectionViewListCell *cell, NSIndexPath *ip, FAQItem *item) { UIListContentConfiguration *content = [cell defaultContentConfiguration]; content.text = item.title; content.secondaryText = item.content; cell.contentConfiguration = content; }]; // ⭐ 3. DataSource self.dataSource = [[UICollectionViewDiffableDataSource alloc] initWithCollectionView:self.collectionView cellProvider:^UICollectionViewCell *(UICollectionView *cv, NSIndexPath *ip, FAQItem *item) { return [cv dequeueConfiguredReusableCellWithRegistration:reg forIndexPath:ip item:item]; }]; // ⭐ 4. Section snapshot —— 关键：append child NSDiffableDataSourceSectionSnapshot *snap = [NSDiffableDataSourceSectionSnapshot new]; for (FAQItem *parent in self.items) { [snap appendItems:@[parent]]; [snap appendItems:parent.children intoParentItem:parent]; [snap expandItems:@[parent]]; // 默认是否展开 } [self.dataSource applySnapshot:snap toSection:@"main" animatingDifferences:YES]; }
Diffable + Outline 的优势：
· 系统帮你处理"父展开 → 子插入"的动画
· 自动 diff，update 数据不用手动算 indexPath
· 自带 chevron 和缩进，不用自己画
· 性能优于传统 reloadData

⚖️ 两种方案对比

维度传统 (UITableView)现代 (Diffable)
最低系统iOS 6+iOS 13+
代码量多（手动管理 expanded set + heightCache）少（snapshot 一把梭）
动画质量需自己设 RowAnimation系统自动 diff 动画
嵌套展开不支持，要自己实现原生支持多级 outline
性能大数据 reloadData 卡diff 后只更新变化部分
无障碍需手动设置自动支持 VoiceOver outline 导航

⚠️ 实战易错点

坑 1：cell 复用时 chevron 状态错乱
cell 复用前可能是展开态，复用到一个折叠 indexPath 时如果不重置 chevron，会显示成 90 度旋转。
解决：在 cellForRow 里强制 setExpanded:animated:NO。
坑 2：高度缓存不清
cell 内容变了（比如刷新数据），heightCache 还是老的高度，会 layout 错乱。
解决：reload 时 [heightCache removeAllObjects]。
坑 3：endUpdates 内嵌套异步
beginUpdates / endUpdates 之间不能 dispatch_async，否则更新不在同一事务里。
优化技巧：富文本展开内容用 YYLabel
展开后如果是几百字的富文本，用 YYLabel 异步排版，YYTextLayout 子线程算好缓存进 model。
