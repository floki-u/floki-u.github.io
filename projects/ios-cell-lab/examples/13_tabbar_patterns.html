📦 完整实现 —— 凸起 TabBar（小红书/抖音通用）

系统 UITabBarController 不直接支持中央凸起按钮，需自定义 UITabBar

1️⃣ 自定义 TabBar 子类

// CustomTabBar.h @interface CustomTabBar : UITabBar @property (nonatomic, copy) void (^onCenterButtonTap)(void); @end // CustomTabBar.m @implementation CustomTabBar { UIButton *_centerButton; } - (instancetype)initWithFrame:(CGRect)frame { if (self = [super initWithFrame:frame]) { _centerButton = [UIButton buttonWithType:UIButtonTypeCustom]; [_centerButton setImage:[UIImage systemImageNamed:@"plus"] forState:UIControlStateNormal]; _centerButton.tintColor = [UIColor whiteColor]; _centerButton.backgroundColor = [UIColor colorWithRed:1.0 green:0.14 blue:0.26 alpha:1]; _centerButton.layer.cornerRadius = 14; _centerButton.layer.shadowColor = [UIColor colorWithRed:1.0 green:0.14 blue:0.26 alpha:0.4].CGColor; _centerButton.layer.shadowOpacity = 1; _centerButton.layer.shadowRadius = 8; _centerButton.layer.shadowOffset = CGSizeMake(0, 2); [_centerButton addTarget:self action:@selector(centerTapped) forControlEvents:UIControlEventTouchUpInside]; [self addSubview:_centerButton]; } return self; } - (void)layoutSubviews { [super layoutSubviews]; // ⭐ 1. 把中央按钮摆放到正中 CGFloat btnW = 44, btnH = 28; _centerButton.frame = CGRectMake((self.bounds.size.width - btnW) / 2, (49 - btnH) / 2, // 49 是系统 TabBar 内容高度 btnW, btnH); // ⭐ 2. 把系统的 4 个 tabBarButton 重新均分布局 // 默认会占满中间空隙，需要手动让出中间 NSMutableArray *tabButtons = [NSMutableArray array]; for (UIView *v in self.subviews) { if ([NSStringFromClass(v.class) isEqualToString:@"UITabBarButton"]) { [tabButtons addObject:v]; } } CGFloat tabW = self.bounds.size.width / (tabButtons.count + 1); NSInteger mid = tabButtons.count / 2; [tabButtons enumerateObjectsUsingBlock:^(UIView *btn, NSUInteger i, BOOL *stop) { CGFloat x = i * tabW; if (i >= mid) x += tabW; // ⭐ 中间留出一个 tab 宽度给中央按钮 btn.frame = CGRectMake(x, btn.frame.origin.y, tabW, btn.frame.size.height); }]; } - (void)centerTapped { if (self.onCenterButtonTap) self.onCenterButtonTap(); } // ⭐ 关键：让超出 TabBar 区域的中央按钮也能响应点击（如果按钮高出 TabBar） - (UIView *)hitTest:(CGPoint)point withEvent:(UIEvent *)event { if (![self pointInside:point withEvent:event]) { CGPoint p = [self convertPoint:point toView:_centerButton]; if ([_centerButton pointInside:p withEvent:event]) { return _centerButton; } } return [super hitTest:point withEvent:event]; } @end

2️⃣ 替换系统 TabBar

@implementation MainTabBarController - (void)viewDidLoad { [super viewDidLoad]; // ⭐ 用 KVC 把系统 tabBar 替换成自定义 CustomTabBar *bar = [[CustomTabBar alloc] init]; [self setValue:bar forKey:@"tabBar"]; __weak typeof(self) weakSelf = self; bar.onCenterButtonTap = ^{ [weakSelf presentPublishViewController]; }; // ⭐ 设置 4 个 viewController（中央按钮不算 tab） self.viewControllers = @[ [self wrap:[HomeVC new] title:@"首页" icon:@"house.fill"], [self wrap:[ShopVC new] title:@"购物" icon:@"bag.fill"], [self wrap:[MessageVC new] title:@"消息" icon:@"message.fill"], [self wrap:[ProfileVC new] title:@"我" icon:@"person.fill"], ]; } - (void)presentPublishViewController { // ⭐ 中央按钮不切 tab，而是 modal 出发布页 PublishVC *vc = [[PublishVC alloc] init]; vc.modalPresentationStyle = UIModalPresentationFullScreen; [self presentViewController:vc animated:YES completion:nil]; } @end

3️⃣ 双击 Tab 触发刷新（抖音/微博通用）

// UITabBarControllerDelegate - (void)tabBarController:(UITabBarController *)tbc didSelectViewController:(UIViewController *)vc { // ⭐ 检测是否是"重复点击当前 tab" static UIViewController *lastVC = nil; static NSTimeInterval lastTime = 0; NSTimeInterval now = [NSDate timeIntervalSinceReferenceDate]; if (vc == lastVC && (now - lastTime) < 0.5) { // 双击间隔 < 500ms，触发刷新 if ([vc respondsToSelector:@selector(scrollToTopAndRefresh)]) { [(id)vc scrollToTopAndRefresh]; } } lastVC = vc; lastTime = now; }
为什么用 hitTest 处理中央按钮？
如果中央按钮高于 TabBar（凸起设计），按钮顶部超出 TabBar 的部分点不到。重写 hitTest:withEvent: 让事件穿透到 _centerButton 才能正常响应。

🔴 徽标（Badge）管理 — 三家做法对比

// 微信式：精确数字 + 上限 - (void)updateUnreadCount:(NSInteger)count { self.tabBarItem.badgeValue = count > 0 ? (count > 99 ? @"99+" : [NSString stringWithFormat:@"%ld", count]) : nil; } // 小红点（不显示数字） - (void)showRedDot:(BOOL)show { if (show) { self.tabBarItem.badgeValue = @""; // 空字符串显示一个小红点 self.tabBarItem.badgeColor = [UIColor systemRedColor]; } else { self.tabBarItem.badgeValue = nil; } } // 设备级徽标（App icon 的红点，需 push 权限） [UIApplication.sharedApplication setApplicationIconBadgeNumber:count];
徽标的体验红线：
1. 数字超过 99+ 一律显示 "99+"，避免长数字撑破 UI
2. 红点不能滥用 —— 微信"通讯录"的红点是有了新好友请求才显示，不是"有任何更新"
3. App 进入对应页面后徽标必须立刻清掉，不要等到下次进入才清

⚖️ 反例 vs 正例

❌ 反例：5 个普通 Tab，全是文字

常见错误：信息架构混乱，把"创建"埋进二级菜单。
后果：核心动作（发布/购买）的转化率显著下降，因为入口深度 +1 就要损失 30%+ 用户。

✅ 正例：核心动作中央 CTA

抖音、小红书、闲鱼、Keep、知乎都用这套：
中央按钮永远是 App 最希望用户做的那个动作。
视觉上凸起 + 品牌色，用户一眼看到。

🎓 设计亮点提炼（可借鉴）

借鉴 1（来自微信）：图标的"实心/线性"切换
未选中用线性 icon，选中用实心 icon。这种"形状变化"比单纯"颜色变化"更易感知，对老年用户尤其友好。
借鉴 2（来自抖音）：永远黑色 TabBar
内容沉浸式 App 里，黑色 TabBar 不会和内容争抢注意力。永远黑色 = 永远不切深浅色（给视频/图片完整呈现）。
借鉴 3（来自小红书）：双 CTA
首页右上角还有一个"+ 发布"入口（次级），中央按钮是主要入口。主入口 + 备用入口能覆盖更多用户习惯。
借鉴 4（来自微博）：双击切换"关注/推荐"
首页 Tab 双击在两种 feed 间快速切换。比顶部分段控件更省手指距离，是"高频操作就近原则"的典范。
借鉴 5（来自 Apple Music / Apple Mail）：选中 Tab 二次点击 = 滚回顶部
用户对此已形成肌肉记忆。一定要支持，否则用户会困惑"为什么这个 App 不行"。
