🔄 PullRefresh — 自定义下拉刷新

系统 UIRefreshControl 太死板，主流 App（淘宝、微博、抖音）都自己做。原理：监听 contentOffset，超过阈值进入"释放即刷新"状态，loading 态用 contentInset "顶住"内容。

🎨 4 个状态可视化

9:41● ● ●
下拉刷新状态机
idle · 静止 contentOffset.y ≥ 0，刷新控件不可见
pulling · 下拉中（progress = 0.5） 用户拉了 30pt / 阈值 60pt，进度环画半圈
readyToRefresh · 即将触发（progress = 1.0） 拉到 60pt 阈值，进度环画满，松手即刷新
refreshing · 刷新中 进度环改为旋转动画，contentInset 顶住 60pt

🧠 4 状态状态机

完整流程：
idle →（手指开始下拉）→ pulling（progress 0~1）→（拉过阈值松手）→ refreshing →（数据返回）→ idle
关键节点：
· pulling 阶段：用 progress 驱动 UI（如进度环、箭头旋转）
· readyToRefresh：拉到阈值时震动反馈（haptic）
· refreshing：禁用手势，contentInset.top += headerHeight 顶住
· 结束：恢复 contentInset，可选播放"刷新完成"动画

📦 完整代码 —— PullRefreshHeader

基于 KVO 监听 contentOffset，无侵入挂载到任何 UIScrollView

1️⃣ 头视图接口

// PullRefreshHeader.h typedef NS_ENUM(NSInteger, PullRefreshState) { PullRefreshStateIdle, PullRefreshStatePulling, PullRefreshStateReadyToRefresh, PullRefreshStateRefreshing, }; @interface PullRefreshHeader : UIView @property (nonatomic, copy) void (^onRefresh)(void); - (void)attachToScrollView:(UIScrollView *)scrollView; - (void)endRefreshing; @end

2️⃣ 实现 —— KVO 监听 + 状态机

static const CGFloat kRefreshHeight = 60; @implementation PullRefreshHeader { __weak UIScrollView *_scrollView; PullRefreshState _state; UIEdgeInsets _originalInset; CAShapeLayer *_progressLayer; CAShapeLayer *_bgLayer; } - (instancetype)init { if (self = [super initWithFrame:CGRectMake(0, -kRefreshHeight, 0, kRefreshHeight)]) { self.backgroundColor = [UIColor clearColor]; [self setupProgressLayer]; } return self; } - (void)setupProgressLayer { // ⭐ 用 CAShapeLayer 画进度环，旋转/进度动画走 GPU UIBezierPath *path = [UIBezierPath bezierPathWithArcCenter:CGPointMake(25, 25) radius:20 startAngle:-M_PI_2 endAngle:3 * M_PI_2 clockwise:YES]; _bgLayer = [CAShapeLayer layer]; _bgLayer.path = path.CGPath; _bgLayer.strokeColor = [UIColor colorWithWhite:0.9 alpha:1].CGColor; _bgLayer.fillColor = [UIColor clearColor].CGColor; _bgLayer.lineWidth = 3; [self.layer addSublayer:_bgLayer]; _progressLayer = [CAShapeLayer layer]; _progressLayer.path = path.CGPath; _progressLayer.strokeColor = [UIColor systemBlueColor].CGColor; _progressLayer.fillColor = [UIColor clearColor].CGColor; _progressLayer.lineWidth = 3; _progressLayer.lineCap = kCALineCapRound; _progressLayer.strokeEnd = 0; [self.layer addSublayer:_progressLayer]; } - (void)attachToScrollView:(UIScrollView *)scrollView { _scrollView = scrollView; _originalInset = scrollView.contentInset; [scrollView addSubview:self]; // ⭐ 用 KVO 监听 contentOffset [scrollView addObserver:self forKeyPath:@"contentOffset" options:NSKeyValueObservingOptionNew context:NULL]; } - (void)observeValueForKeyPath:(NSString *)keyPath ofObject:(id)object change:(NSDictionary *)change context:(void *)context { if (![keyPath isEqualToString:@"contentOffset"]) return; [self scrollViewDidScroll]; } - (void)scrollViewDidScroll { if (_state == PullRefreshStateRefreshing) return; CGFloat offset = _scrollView.contentOffset.y + _originalInset.top; CGFloat pulled = -offset; // 用户实际下拉的距离（正数） if (pulled <= 0) { // 没下拉，回到 idle [self transitionToState:PullRefreshStateIdle]; _progressLayer.strokeEnd = 0; return; } // ⭐ 计算进度并更新进度环 CGFloat progress = MIN(1.0, pulled / kRefreshHeight); [CATransaction begin]; [CATransaction setDisableActions:YES]; // 禁用隐式动画，跟手 _progressLayer.strokeEnd = progress; [CATransaction commit]; // ⭐ 状态切换 + haptic 反馈 if (_scrollView.isDragging) { if (progress >= 1.0 && _state != PullRefreshStateReadyToRefresh) { [self transitionToState:PullRefreshStateReadyToRefresh]; // ⭐ 触发 haptic（拉到位的反馈） [[[UIImpactFeedbackGenerator alloc] initWithStyle:UIImpactFeedbackStyleMedium] impactOccurred]; } else if (progress < 1.0) { [self transitionToState:PullRefreshStatePulling]; } } else { // 松手时如果在 ready 状态 → 触发刷新 if (_state == PullRefreshStateReadyToRefresh) { [self beginRefreshing]; } } } - (void)beginRefreshing { [self transitionToState:PullRefreshStateRefreshing]; // ⭐ 用 contentInset 把 header 顶住 [UIView animateWithDuration:0.25 animations:^{ UIEdgeInsets i = _originalInset; i.top += kRefreshHeight; _scrollView.contentInset = i; }]; // ⭐ 进度环改为旋转动画 [self startSpinAnimation]; // ⭐ 通知业务方 if (self.onRefresh) self.onRefresh(); } - (void)endRefreshing { [_progressLayer removeAllAnimations]; [UIView animateWithDuration:0.25 animations:^{ _scrollView.contentInset = _originalInset; } completion:^(BOOL done) { [self transitionToState:PullRefreshStateIdle]; _progressLayer.strokeEnd = 0; }]; } - (void)startSpinAnimation { CABasicAnimation *spin = [CABasicAnimation animationWithKeyPath:@"transform.rotation.z"]; spin.fromValue = @0; spin.toValue = @(2 * M_PI); spin.duration = 0.8; spin.repeatCount = HUGE_VALF; [_progressLayer addAnimation:spin forKey:@"spin"]; } - (void)transitionToState:(PullRefreshState)newState { if (_state == newState) return; _state = newState; // 子类可重写做更多 UI 反馈 } - (void)dealloc { [_scrollView removeObserver:self forKeyPath:@"contentOffset"]; } @end
关键技术点：
· CATransaction setDisableActions:YES —— 禁用 strokeEnd 的隐式动画，让进度环跟手
· UIImpactFeedbackGenerator —— 拉到阈值时震动一下，体验质的飞跃
· contentInset.top += kRefreshHeight —— refresh 期间顶住，避免 header 被遮回去
· CAShapeLayer + strokeEnd —— 进度环画法，比 drawRect 高效百倍

3️⃣ 业务侧使用

- (void)viewDidLoad { self.refreshHeader = [[PullRefreshHeader alloc] init]; [self.refreshHeader attachToScrollView:self.tableView]; __weak typeof(self) weakSelf = self; self.refreshHeader.onRefresh = ^{ [API fetchLatest:^(NSArray *list) { weakSelf.items = list; [weakSelf.tableView reloadData]; [weakSelf.refreshHeader endRefreshing]; }]; }; }

⚖️ 反例 vs 正例

❌ 反例：UIView 动画驱动进度环

- (void)scrollViewDidScroll:...{ // ❌ 用 UIView animate，每帧主线程 [UIView animateWithDuration:0.1 animations:^{ _progressView.transform = CGAffineTransformMakeRotation(progress * M_PI); }]; // 滚动时每帧都触发动画排队，必卡 }

✅ 正例：CATransaction + strokeEnd

- (void)scrollViewDidScroll { [CATransaction begin]; [CATransaction setDisableActions:YES]; _progressLayer.strokeEnd = progress; [CATransaction commit]; // ✅ 禁用隐式动画，立刻应用，0 排队 }

🚀 进阶：上拉加载更多 (Footer)

原理对称：
· 监听 contentOffset.y + bounds.height 是否接近 contentSize.height
· 接近时显示 footer 的 loading 态
· 加载完成插入新数据后，contentOffset 不变（避免视觉跳变）
- (void)scrollViewDidScroll { CGFloat bottomOffset = _scrollView.contentSize.height - _scrollView.contentOffset.y - _scrollView.bounds.size.height; if (bottomOffset < 100 && !_isLoadingMore && _hasMore) { _isLoadingMore = YES; if (self.onLoadMore) self.onLoadMore(); } }

⚠️ 实战易错点

坑 1：KVO 没移除导致崩溃
dealloc 必须 removeObserver，否则 scrollView 可能晚于 header 释放，触发 KVO 给已释放对象，崩。
坑 2：refresh 期间用户继续拉，状态错乱
scrollViewDidScroll 开头判断 if (_state == Refreshing) return，避免重入。
坑 3：contentInset 没恢复
endRefreshing 必须把 contentInset 改回 _originalInset，否则下次进入页面顶部会多 60pt 空白。
坑 4：导航栏 largeTitle 时 inset 计算错
iOS 11+ largeTitle 会动态改 inset，要么用 adjustedContentInset，要么直接用 contentInsetAdjustmentBehavior = Never。
最佳实践：用 MJRefresh
生产项目直接用 MJRefresh。它已处理了几百个边界 case（横屏、双手势、多 ScrollView 嵌套等）。但你必须懂原理才能 debug 它。
