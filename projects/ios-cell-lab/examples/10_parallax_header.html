🧩 视觉效果拆解

这一个交互里同时包含 3 件事：
1. 视差跟随 —— 头图以 0.5 倍速度向上移动（让感觉"在更远的地方"）
2. 下拉放大 —— 用户下拉时头图保持顶部贴合并放大（仪式感）
3. 导航栏渐变 —— 头图滚出后导航栏从透明变成白色 + 模糊背景
4. 标题渐入 —— 头图被遮住时显示标题（视觉接力）

📦 完整代码实现

使用 UIScrollView delegate 监听 contentOffset，所有动画都跟随手指实时反馈

1️⃣ 布局结构

@interface ProfileViewController () <UIScrollViewDelegate> @property (nonatomic, strong) UIImageView *headerImageView; // 视差头图 @property (nonatomic, strong) UIVisualEffectView *navBlurView; // 导航栏模糊背景 @property (nonatomic, strong) UILabel *navTitleLabel; // 折叠后显示的标题 @property (nonatomic, strong) UITableView *tableView; // 内容列表 @end static const CGFloat kHeaderHeight = 240; static const CGFloat kNavBarHeight = 88; // 含状态栏 - (void)viewDidLoad { [super viewDidLoad]; // ⭐ 1. 头图（位于 tableView 后面） _headerImageView = [[UIImageView alloc] initWithFrame:CGRectMake(0, 0, self.view.bounds.size.width, kHeaderHeight)]; _headerImageView.contentMode = UIViewContentModeScaleAspectFill; _headerImageView.clipsToBounds = YES; _headerImageView.image = [UIImage imageNamed:@"profile_bg"]; [self.view addSubview:_headerImageView]; // ⭐ 2. tableView（透明背景，内容偏移开头图） _tableView = [[UITableView alloc] initWithFrame:self.view.bounds]; _tableView.delegate = self; _tableView.dataSource = self; _tableView.backgroundColor = [UIColor clearColor]; // 给 tableView 顶部留出 header 高度的位置 _tableView.contentInset = UIEdgeInsetsMake(kHeaderHeight, 0, 0, 0); _tableView.contentOffset = CGPointMake(0, -kHeaderHeight); [self.view addSubview:_tableView]; // ⭐ 3. 导航栏（在最上层） _navBlurView = [[UIVisualEffectView alloc] initWithEffect:[UIBlurEffect effectWithStyle:UIBlurEffectStyleSystemMaterial]]; _navBlurView.frame = CGRectMake(0, 0, self.view.bounds.size.width, kNavBarHeight); _navBlurView.alpha = 0; // 默认透明 [self.view addSubview:_navBlurView]; _navTitleLabel = [[UILabel alloc] init]; _navTitleLabel.text = @"张三的主页"; _navTitleLabel.font = [UIFont systemFontOfSize:17 weight:UIFontWeightSemibold]; _navTitleLabel.alpha = 0; _navTitleLabel.frame = CGRectMake(0, 44, self.view.bounds.size.width, 44); _navTitleLabel.textAlignment = NSTextAlignmentCenter; [self.view addSubview:_navTitleLabel]; }

2️⃣ 核心：scrollViewDidScroll —— 一切动画的源头

- (void)scrollViewDidScroll:(UIScrollView *)scrollView { // ⭐ 计算"用户拖动了多少距离"（offset 是负数表示下拉） CGFloat offset = scrollView.contentOffset.y + kHeaderHeight; // =============== 1. 视差头图 =============== if (offset < 0) { // 下拉：头图放大并保持顶部贴合（橡皮筋效果） CGFloat scale = 1 + (-offset) / kHeaderHeight; // ⭐ 用 transform 而不是改 frame，避免触发 layout _headerImageView.transform = CGAffineTransformMakeScale(scale, scale); _headerImageView.frame = CGRectMake(0, 0, self.view.bounds.size.width, kHeaderHeight); } else { // 上滑：以 0.5 倍速向上移动（视差感） // ⭐ 关键：移动 0.5*offset 而不是 1.0*offset，让"远景慢于近景" _headerImageView.transform = CGAffineTransformIdentity; _headerImageView.frame = CGRectMake(0, -offset * 0.5, self.view.bounds.size.width, kHeaderHeight); } // =============== 2. 导航栏渐变 =============== // ⭐ 滚动 (kHeaderHeight - kNavBarHeight) 距离时，导航栏完全显现 CGFloat threshold = kHeaderHeight - kNavBarHeight; CGFloat alpha = MAX(0, MIN(1, offset / threshold)); _navBlurView.alpha = alpha; _navTitleLabel.alpha = alpha; // =============== 3. 状态栏样式联动 =============== // 头图（深色）覆盖时用浅色状态栏，白色背景时用深色状态栏 [self setNeedsStatusBarAppearanceUpdate]; } - (UIStatusBarStyle)preferredStatusBarStyle { CGFloat offset = self.tableView.contentOffset.y + kHeaderHeight; CGFloat threshold = kHeaderHeight - kNavBarHeight; return (offset / threshold) > 0.7 ? UIStatusBarStyleDarkContent : UIStatusBarStyleLightContent; }
为什么用 transform 而不是改 frame？
· transform 走 GPU 合成，不触发 layout/draw，每帧 < 1ms
· 改 frame 会触发整个 view 树的重新布局，滚动时 60fps 难保
· 这是滚动联动动画的铁律：能用 transform 就别动 frame

⚖️ 反例 vs 正例

❌ 反例：改 frame + 重布局

- (void)scrollViewDidScroll:...{ CGFloat offset = scrollView.contentOffset.y; // ❌ 直接改 frame CGRect f = _headerImageView.frame; f.origin.y = -offset * 0.5; f.size.height = kHeaderHeight + MAX(0, -offset); _headerImageView.frame = f; // 触发 layoutSubviews → 卡顿 }
滚动到 50fps，老设备掉到 30fps

✅ 正例：transform + GPU 合成

- (void)scrollViewDidScroll:...{ CGFloat offset = scrollView.contentOffset.y; if (offset < 0) { _headerImageView.transform = CGAffineTransformMakeScale(scale, scale); } else { _headerImageView.transform = CGAffineTransformMakeTranslation(0, -offset*0.5); } // ✅ 仅 GPU 合成，不重布局 }
稳 60fps，hitch ratio 接近 0

🚀 进阶：更高级的实现

方案 A：UIScrollViewDelegate（本文方案）
· 优点：兼容所有 iOS 版本，逻辑清晰
· 缺点：scrollViewDidScroll 回调密集，逻辑都要塞这里
方案 B：UICollectionView + Compositional Layout（iOS 13+）
· 把头图做成一个 supplementary view，section 滚动时自动布局
· 配合 visibleItemsInvalidationHandler 做更精细的视差
方案 C：UILargeContentViewer + UINavigationController（iOS 11+）
· 用系统大标题导航，navigationItem.largeTitleDisplayMode 自带折叠效果
· 适合系统风格的设置页

⚠️ 实战易错点

坑 1：contentInset 没设
tableView 的 contentInset.top 必须等于头图高度，否则首屏 cell 会被头图盖住。同时 contentOffset 初始值必须是 -kHeaderHeight。
坑 2：iOS 11+ 的 safeAreaInsets 自动调整
self.tableView.contentInsetAdjustmentBehavior = UIScrollViewContentInsetAdjustmentNever;
否则系统会"贴心"地再加一次 inset，导致内容下移。
坑 3：状态栏样式跳变
setNeedsStatusBarAppearanceUpdate 不能在 scrollViewDidScroll 每帧调，会卡。
解决：加状态变量，只在样式真的变化时才调。
坑 4：模糊背景在低端机卡
UIVisualEffectView 在 iPhone 8 以下设备开销大。可以根据设备型号降级为半透明纯色。
最佳实践：把 offset 计算抽成方法
scrollViewDidScroll 里只做"算出 alpha → 赋给 view"，所有阈值算 / 状态判断抽成纯函数，方便单测。
