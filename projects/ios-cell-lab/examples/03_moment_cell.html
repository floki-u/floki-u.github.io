3️⃣ MomentCell（朋友圈：图片九宫格）

朋友圈 cell 的核心难点是 图片九宫格 + 圆角。 如果每张图都用 clipsToBounds 裁圆角，9 张图 = 9 次离屏 + 9 次混合，必卡。 本节讲"零离屏圆角图片"的工业级方案。

🚨 核心问题：9 张图的圆角代价

1
每张图用 cornerRadius=4 + clipsToBounds=YES → 每张图都触发一次离屏，9 张图 = 9 次
2
滚动时一屏可能有 2~3 个朋友圈 → 27 次离屏 + 27 次合成 → FPS 直接掉到 30 以下
💡 解法： 利用 SDWebImage / Kingfisher 的 Transformer，让图片在解码阶段就把圆角处理掉， UIImageView 完全不需要 clipsToBounds = 0 离屏

✅ 关键技巧：解码时切圆角

❌ 反例：UIImageView 自己 clip
UIImageView *gridImg =
  [[UIImageView alloc] init];
gridImg.layer.cornerRadius = 4;
gridImg.clipsToBounds = YES;

[gridImg sd_setImageWithURL:url];

// ❌ 9 张图 = 9 次离屏渲染
// ❌ Color Off-screen
//   九宫格区域全黄
✅ 正例：Transformer 解码切圆角
UIImageView *gridImg =
  [[UIImageView alloc] init];
// ⭐ 不设 cornerRadius
// ⭐ 不开 clipsToBounds

SDWebImageRoundCornerTransformer *t =
  [[SDWebImageRoundCornerTransformer alloc]
    initWithRadius:4
           corners:UIRectCornerAllCorners
       borderWidth:0 borderColor:nil];

[gridImg sd_setImageWithURL:url
     placeholderImage:nil
              options:0
              context:@{
  SDWebImageContextImageTransformer: t
}];

// ✅ 切好的图自带圆角
// ✅ 0 离屏，0 clip
📖 原理： SDWebImage 下载图片后会先解码（在子线程），Transformer 介入这个阶段， 把图片直接画在一个圆角 UIBezierPath 裁剪过的 context 里，输出的 UIImage 本身就是圆角的。 UIImageView 显示时只需要正常贴图，不需要任何裁切操作。

🦋 Kingfisher 等价方案（Swift）

import Kingfisher

let processor = RoundCornerImageProcessor(
  cornerRadius: 4,
  targetSize: CGSize(width: 78, height: 78),
  roundingCorners: .all
)

gridImageView.kf.setImage(
  with: url,
  placeholder: nil,
  options: [.processor(processor), .cacheSerializer(FormatIndicatedCacheSerializer.png)]
)

// ⭐ 注意 cacheSerializer 用 png，否则 jpeg 会丢透明通道
// ⭐ Kingfisher 的 cache key 会自动包含 processor identifier

✅ 配套：文本子线程预算

朋友圈正文长度不定，必须在子线程算好高度
@interface MomentViewModel : NSObject
@property (nonatomic, strong) Moment *moment;
@property (nonatomic, assign) CGFloat cachedHeight;
@property (nonatomic, assign) CGRect textFrame;
@property (nonatomic, assign) CGRect gridFrame;
@end

@implementation MomentViewModel

- (void)prepareLayoutIfNeeded {
  if (self.cachedHeight > 0) return;

  CGFloat top = 16, x = 62;
  CGFloat contentWidth = 316;

  // 正文高度：boundingRectWithSize 子线程算
  NSDictionary *attr = @{
    NSFontAttributeName: [UIFont systemFontOfSize:15]
  };
  CGRect textRect = [self.moment.text
    boundingRectWithSize:CGSizeMake(contentWidth, CGFLOAT_MAX)
                options:NSStringDrawingUsesLineFragmentOrigin
             attributes:attr context:nil];
  self.textFrame = CGRectMake(x, top + 22, contentWidth, ceil(textRect.size.height));

  // 图片 grid 高度：行数 × (78 + 4) - 4
  int count = (int)self.moment.imageURLs.count;
  int rows = (count + 2) / 3;
  CGFloat gridH = rows > 0 ? rows * 82 - 4 : 0;
  self.gridFrame = CGRectMake(x, CGRectGetMaxY(self.textFrame) + 8,
                              242, gridH);

  self.cachedHeight = CGRectGetMaxY(self.gridFrame) + 40;
}

@end

📦 MomentCell.m 关键实现

@implementation MomentCell

- (instancetype)initWithStyle:... {
  if (self = [super ...]) {
    self.contentView.backgroundColor = [UIColor whiteColor];
    self.contentView.opaque = YES;

    // 头像：方角，可直接 cornerRadius + cornerCurve
    _avatarView = [[UIImageView alloc] init];
    _avatarView.layer.cornerRadius = 6;
    _avatarView.layer.cornerCurve = kCACornerCurveContinuous;
    // ✅ 不加 clipsToBounds
    [self.contentView addSubview:_avatarView];

    // 9 个 grid imageView
    _gridImageViews = [NSMutableArray array];
    for (int i = 0; i < 9; i++) {
      UIImageView *iv = [[UIImageView alloc] init];
      iv.contentMode = UIViewContentModeScaleAspectFill;
      iv.opaque = YES;
      iv.backgroundColor = [UIColor colorWithWhite:0.9 alpha:1];
      // ⭐ 不设 cornerRadius，不 clipsToBounds
      // 圆角由 SDWebImageTransformer 在解码时切好
      iv.hidden = YES;
      [self.contentView addSubview:iv];
      [_gridImageViews addObject:iv];
    }
  }
  return self;
}

- (void)prepareForReuse {
  [super prepareForReuse];
  for (UIImageView *iv in self.gridImageViews) {
    [iv sd_cancelCurrentImageLoad];
    iv.image = nil;
    iv.hidden = YES;
  }
  [self.avatarView sd_cancelCurrentImageLoad];
  self.avatarView.image = nil;
  self.textLabel.text = nil;
}

- (void)configureWithViewModel:(MomentViewModel *)vm {
  self.textLabel.frame = vm.textFrame;
  self.textLabel.text = vm.moment.text;

  // ⭐ 配置 9 宫格
  static SDWebImageRoundCornerTransformer *transformer;
  static dispatch_once_t once;
  dispatch_once(&once, ^{
    transformer = [[SDWebImageRoundCornerTransformer alloc]
      initWithRadius:4 corners:UIRectCornerAllCorners
        borderWidth:0 borderColor:nil];
  });

  for (int i = 0; i < 9; i++) {
    UIImageView *iv = self.gridImageViews[i];
    if (i < vm.moment.imageURLs.count) {
      iv.hidden = NO;
      iv.frame = [vm gridFrameAtIndex:i];
      [iv sd_setImageWithURL:vm.moment.imageURLs[i]
            placeholderImage:nil
                     options:0
                     context:@{
        SDWebImageContextImageTransformer: transformer
      }];
    } else {
      iv.hidden = YES;
    }
  }
}

@end
