📦 完整代码 —— 现代 API（iOS 11+）

所有 swipe 按钮、动画、长滑触发都由系统处理，开发者只写"按下后做什么"

1️⃣ 右滑菜单（trailing — 从右往左滑出）

// UITableViewDelegate - (UISwipeActionsConfiguration *)tableView:(UITableView *)tableView trailingSwipeActionsConfigurationForRowAtIndexPath:(NSIndexPath *)indexPath { Message *msg = self.messages[indexPath.row]; // ⭐ 删除 —— destructive 风格自动变红 UIContextualAction *del = [UIContextualAction contextualActionWithStyle:UIContextualActionStyleDestructive title:@"删除" handler:^(UIContextualAction *action, UIView *sourceView, void (^completion)(BOOL)) { [self deleteMessage:msg atIndex:indexPath.row]; completion(YES); // ⭐ 必须调用，告诉系统操作完成 }]; del.image = [UIImage systemImageNamed:@"trash.fill"]; del.backgroundColor = [UIColor systemRedColor]; // ⭐ 置顶 —— normal 风格 UIContextualAction *pin = [UIContextualAction contextualActionWithStyle:UIContextualActionStyleNormal title:(msg.isPinned ? @"取消置顶" : @"置顶") handler:^(UIContextualAction *action, UIView *sourceView, void (^completion)(BOOL)) { [self togglePin:msg]; completion(YES); }]; pin.image = [UIImage systemImageNamed:@"pin.fill"]; pin.backgroundColor = [UIColor systemGreenColor]; // ⭐ 静音 UIContextualAction *mute = [UIContextualAction contextualActionWithStyle:UIContextualActionStyleNormal title:@"静音" handler:^(UIContextualAction *action, UIView *sourceView, void (^completion)(BOOL)) { [self muteMessage:msg]; completion(YES); }]; mute.image = [UIImage systemImageNamed:@"bell.slash.fill"]; mute.backgroundColor = [UIColor systemOrangeColor]; // ⭐ 数组顺序 = 从右往左 UISwipeActionsConfiguration *cfg = [UISwipeActionsConfiguration configurationWithActions:@[del, pin, mute]]; // ⭐ 是否允许"长滑直接触发第一个"（默认 YES） cfg.performsFirstActionWithFullSwipe = YES; return cfg; }
关键 API 详解：
· UIContextualActionStyleDestructive —— 系统自动变红，长滑触发时有删除动画
· UIContextualActionStyleNormal —— 普通按钮，颜色自定义
· completion(YES) —— 告诉系统按钮逻辑已执行，可以收回菜单
· completion(NO) —— 操作失败，菜单保持展开（比如二次确认）
· performsFirstActionWithFullSwipe —— 长滑越过阈值自动触发第一个按钮（邮件 App 删除手感）

2️⃣ 左滑菜单（leading — 从左往右滑出）

- (UISwipeActionsConfiguration *)tableView:(UITableView *)tableView leadingSwipeActionsConfigurationForRowAtIndexPath:(NSIndexPath *)indexPath { Message *msg = self.messages[indexPath.row]; UIContextualAction *read = [UIContextualAction contextualActionWithStyle:UIContextualActionStyleNormal title:(msg.isRead ? @"标为未读" : @"标为已读") handler:^(UIContextualAction *action, UIView *sourceView, void (^completion)(BOOL)) { msg.isRead = !msg.isRead; completion(YES); }]; read.backgroundColor = [UIColor systemBlueColor]; read.image = [UIImage systemImageNamed:@"envelope.open.fill"]; return [UISwipeActionsConfiguration configurationWithActions:@[read]]; }

3️⃣ 删除时的 cell 退场动画（重要！）

- (void)deleteMessage:(Message *)msg atIndex:(NSInteger)idx { // ⭐ 数据源和 UI 必须在同一个事务里更新，否则会崩溃 [self.messages removeObjectAtIndex:idx]; [self.tableView deleteRowsAtIndexPaths:@[[NSIndexPath indexPathForRow:idx inSection:0]] withRowAnimation:UITableViewRowAnimationLeft]; // 后台请求异步删除 [API deleteMessageWithId:msg.identifier completion:^(NSError *err) { if (err) { // 失败回滚：插回去 [self.messages insertObject:msg atIndex:idx]; [self.tableView insertRowsAtIndexPaths:@[[NSIndexPath indexPathForRow:idx inSection:0]] withRowAnimation:UITableViewRowAnimationFade]; [self showToast:@"删除失败"]; } }]; }

⚖️ 反例 vs 正例

❌ 反例：自己 hack PanGesture

// 在 cell 上加 UIPanGestureRecognizer，手动算 transform - (void)handlePan:(UIPanGestureRecognizer *)pan { CGPoint t = [pan translationInView:self]; self.contentView.transform = CGAffineTransformMakeTranslation(t.x, 0); // ❌ 没有橡皮筋、没有 haptic、不能多按钮 // ❌ 同时多个 cell 滑出无法协调 // ❌ 长滑触发要自己写阈值判断 }

✅ 正例：UISwipeActionsConfiguration

- (UISwipeActionsConfiguration *)tableView:... trailingSwipeActionsConfigurationFor... { UIContextualAction *del = ...; return [UISwipeActionsConfiguration configurationWithActions:@[del]]; } // ✅ 系统全包：橡皮筋、haptic、长滑、互斥 // ✅ 自适应深色模式 // ✅ Voice Over 无障碍自动支持

🚀 进阶：CollectionView 的等价 API（iOS 14+）

UICollectionView 用 UICollectionLayoutListConfiguration：
UICollectionLayoutListConfiguration *cfg = [[UICollectionLayoutListConfiguration alloc] initWithAppearance:UICollectionLayoutListAppearancePlain]; cfg.trailingSwipeActionsConfigurationProvider = ^UISwipeActionsConfiguration *(NSIndexPath *ip) { UIContextualAction *del = [UIContextualAction contextualActionWithStyle:UIContextualActionStyleDestructive title:@"删除" handler:^...]; return [UISwipeActionsConfiguration configurationWithActions:@[del]]; }; UICollectionViewLayout *layout = [UICollectionViewCompositionalLayout layoutWithListConfiguration:cfg];

⚠️ 实战易错点

坑 1：忘记调 completion
completion(YES) 必须调用，否则按钮一直 highlight，菜单收不回。
坑 2：删除时数据源和 UI 不同步
正确顺序：先改数据源 → 再 deleteRowsAtIndexPaths。反过来必崩。
坑 3：自定义按钮颜色在 Dark Mode 下变形
用 systemRedColor、systemBlueColor 这些 dynamic color，不要写死 RGB。
坑 4：长滑误触发删除
如果第一个按钮是删除（destructive），performsFirstActionWithFullSwipe = YES 会让用户长滑直接删，要么改顺序、要么关闭这个开关、要么加二次确认。
最佳实践：危险操作做二次确认
destructive handler 里弹 UIAlertController，确认后才真删。completion(NO) 让菜单保持展开，给用户"反悔"的视觉提示。
