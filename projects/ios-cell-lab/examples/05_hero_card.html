5️⃣ HeroCard 动画 ⭐ 光栅化的唯一真实有效场景

前面 4 个 cell 都没用光栅化，因为 cell 复用场景下光栅化是反向优化。 那光栅化到底什么时候用？答案是：「复杂静态 view + transform 动画」。 本节用商品详情页的 Hero 卡片入场动画演示。

🎯 为什么这个场景适合光栅化？

1
渲染代价高：渐变背景 + 复杂阴影（shadowRadius=32）+ 2 个装饰圆光晕 + 多层 subview
2
动画期间内容静态：动画过程中 layer 的 text/color/image 完全不变，只有 transform 在变
3
transform 不让缓存失效：缩放 / 位移 / 透明度变化在合成阶段处理，缓存命中率 100%
🎯 三项全 ✅，光栅化才值得开。 cell 三项全 ❌（内容会变、复用频繁、不是 transform 动画），所以 cell 永远不开。

⏱️ 光栅化的时间线

1
动画开始前：开启光栅化
self.layer.shouldRasterize = YES
self.layer.rasterizationScale = UIScreen.mainScreen.scale
2
第 1 帧：GPU 完整画一遍卡片（渐变 + 阴影 + 装饰）
→ 把结果存进缓存（这一帧是"投资"）
3
第 2 ~ N 帧（动画过程）：transform 不断变化，layer 内容不变
→ 缓存全部命中，GPU 只贴缓存图，省去重画 = 动画丝滑
4
动画结束：立刻关闭光栅化
self.layer.shouldRasterize = NO
⚠️ 不关掉的话，后续如果文字变了 / 价格变了，缓存会反复失效，反而拖慢

📦 HeroCardView.m 完整实现

@implementation HeroCardView

- (instancetype)initWithFrame:(CGRect)frame {
  if (self = [super initWithFrame:frame]) {
    self.backgroundColor = [UIColor whiteColor];
    self.opaque = YES;

    // ✅ 圆角用 cornerCurve，不 clip
    self.layer.cornerRadius = 16;
    self.layer.cornerCurve = kCACornerCurveContinuous;

    // ✅ 阴影用 shadowPath
    self.layer.shadowColor = [UIColor blackColor].CGColor;
    self.layer.shadowOpacity = 0.18;
    self.layer.shadowOffset = CGSizeMake(0, 8);
    self.layer.shadowRadius = 32;

    // 复杂内容：渐变层 + 装饰圆 + 多层 subview
    [self setupComplexSubviews];
  }
  return self;
}

- (void)layoutSubviews {
  [super layoutSubviews];
  // shadowPath 必须在 layoutSubviews 里更新
  self.layer.shadowPath = [UIBezierPath
    bezierPathWithRoundedRect:self.bounds
                cornerRadius:16].CGPath;
}

// ⭐ 真实有效的光栅化用法
- (void)playEntranceAnimation {
  // 1️⃣ 动画前：开启光栅化
  // （此时 layer 内容已稳定，第 1 帧画完就可以缓存）
  self.layer.shouldRasterize = YES;
  self.layer.rasterizationScale = [UIScreen mainScreen].scale;
  // ⚠️ rasterizationScale 必须设，否则 @2x/@3x 屏会模糊

  // 2️⃣ 起始状态：缩放为 0.1
  self.transform = CGAffineTransformMakeScale(0.1, 0.1);

  // 3️⃣ 弹簧动画
  [UIView animateWithDuration:0.6
                          delay:0
         usingSpringWithDamping:0.6
          initialSpringVelocity:0.5
                        options:UIViewAnimationOptionCurveEaseOut
                     animations:^{
    self.transform = CGAffineTransformIdentity;
  } completion:^(BOOL finished) {
    // 4️⃣ ⭐ 动画结束立刻关闭光栅化（关键礼仪）
    // 因为后续可能要响应交互（点击、内容更新），
    // 保持光栅化只会让缓存反复失效
    self.layer.shouldRasterize = NO;
  }];
}

@end

🦋 Swift 版本

extension HeroCardView {
  func playEntranceAnimation() {
    // 1️⃣ 开启光栅化
    layer.shouldRasterize = true
    layer.rasterizationScale = UIScreen.main.scale

    // 2️⃣ 起始状态
    transform = CGAffineTransform(scaleX: 0.1, y: 0.1)

    // 3️⃣ 弹簧动画
    UIView.animate(
      withDuration: 0.6, delay: 0,
      usingSpringWithDamping: 0.6,
      initialSpringVelocity: 0.5,
      options: .curveEaseOut
    ) {
      self.transform = .identity
    } completion: { _ in
      // 4️⃣ ⭐ 动画结束立刻关
      self.layer.shouldRasterize = false
    }
  }
}

🔬 怎么验证光栅化生效了？

用 Simulator 的 Color Hits Green and Misses Red
1
打开 Simulator → Debug → Color Hits Green and Misses Red
2
重播动画，观察 HeroCard 区域：
• 第 1 帧：可能闪一下红色（缓存 miss，正在写入）
• 之后整个动画过程：绿色（缓存全部命中）✅
3
如果你看到大片红色（持续 miss）→ 说明 layer 内容在变，不该开光栅化
🎯 黄金标准： 「绿多 = 留」「红多 = 关」。永远用工具验证，不要凭感觉决定。

✅ 光栅化使用 Checklist

三项全 ✅ 才值得开
✓
layer 内容是静态的（动画期间不会变 text/color/image）
✓
渲染代价高（多层叠加、复杂阴影、渐变）
✓
主要做 transform / 位移 / 透明度 动画

⚠️ 任何一项 ❌，都不要开。cell 三项全 ❌ → cell 永远不要开光栅化。
