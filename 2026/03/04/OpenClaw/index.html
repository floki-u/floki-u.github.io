是否真的需要OpenClaw

AI Agent 时代已经到来，OpenClaw 作为一种全新的交互范式，正在改变我们使用 AI 的方式。本文从个人使用经验出发，分享 OpenClaw 的使用心得、最佳实践以及与其他 AI 工具的协作策略。

本文由GPT-5.4润色，与AI共生哈哈

一、你真的需要 OpenClaw 吗？

1.1 关于使用门槛的误解

首先我非常反对一些 KOL 不负责任的论调——所谓”如果你需要托人帮你安装龙虾，那你其实就用不太上龙虾”。

虽然目前 OpenClaw 确实有不少问题——费 token、难安装、安全性不足、权限管理不完善——但它确实是目前最符合大众使用习惯的 AI Agent 交互方式。

PS：国内各大厂商现在已经推出了各种云端部署方案，甚至本地一键下载的agent桌面应用，你甚至通过他去帮你安装龙虾，不要再花500块去安装了

1.2 AI Agent 的时代已经到来

AI Agent 已经迅速发展到真的能做事情的程度了，但身边绝大多数人还只是和大模型聊天，对 AI 目前发展到什么程度还一无所知。

最快体验 chat 和 Agent 办事能力区别的方法：用 Kimi 官网免费的 Agent 额度，给它一个你能想到的最难的任务——而不是把之前用 chat 的方法给它试。最高支持 50 个附件，你可以发 50 本书给它翻译之类的，或者调研某个你很想做的东西然后写代码实现。不一定能做得很好，但以前不能做的现在可以做了。

当然这个方案不是 AI Agent 的极限，只是我觉得能免费体验到的最聪明最易用的 Agent。最近多了一个 WorkBuddy，我觉得也比较开箱即用，但本质上还是一个 CodeBuddy，行为逻辑和 OpenClaw 不太一样。这篇公众号排版就是靠 WorkBuddy + Claude Opus 4.6 搞定的。

1.3 早期使用体验

司内推出内网版OpenClaw的时候，我基本每周都会用限额，且烧 token 烧得有我用 CodeBuddy 十倍有余。

我拿它完成了纯嘴遁做网页 + 部署的整个环节，但效果远不如我后面用 CodeBuddy 认真做的新网页，而后者的 token 开销应该不及前者十分之一，甚至我用的还是更贵的模型。

这里我想说：越贵的模型办事能力越强，反而越省钱。有条件的请都上目前版本之神 Claude Opus 4.6。

1.4 产品对大众的吸引力

但我还是远远低估了这个产品对大众的吸引力，正如现在一些人依然顽固认为这只是个”打卡点”。

当一个产品足够简单，即使它做得不是很好，即使它很贵，也会有人愿意去用它。

这里有一个广为流传的故事：

一位名叫 Andreas 的 OpenClaw 用户，给经营图书出版社的母亲演示了自己用 OpenClaw 搭建的 AI 机器人 “Robo”。Robo 当场给出了搭建在线订购网站、对接印刷厂物流、打通财务环节的完整方案。母亲立刻说：”快给我装一个。” Andreas 提醒她这东西目前只有大约 80% 的可靠性，调试起来很麻烦。母亲满不在乎地回答：“人类也一样会出错。”

（顺便吐槽：我之前把这个故事的主角记成了 OpenClaw 创始人 Peter，后来让 AI 多方查验才纠正过来。人类的记忆也是会出错的！今日被确诊为 AI 😂）

1.5 为什么聊天软件 + AI Agent 是最佳拍档

就像当时 OpenClaw 在海外风靡一样，当企业微信、QQ、飞书对 OpenClaw 的适配逐渐跟上以后，在国内再次引起爆火。原因很简单——用聊天软件使用 AI Agent，就是非常符合人类的使用习惯！

很多人觉得 OpenClaw 就是个套壳、不好用，是因为他们用了太多更强大的 AI Agent——例如 Cursor、Claude Code 等。尤其是 Claude Code 重度用户，因为 OpenClaw 最初也就是 Peter 想给 Claude Code 配个 Telegram 搞的，他们会觉得 OpenClaw 并没有那么厉害。确实，写代码比不上专业的 Code Agent，我还给我的龙虾配了个 Claude Code，让它写复杂代码的时候用。

但他们忽略了一个关键点： 这些 Agent 使用门槛太高，天然让很多用户觉得——起码要懂一点点代码才能用。Vibe Coding，就算再 vibe，首先它是 coding。但 AI 助手就不一样了，谁不想有个在微信 24 小时听你摆布的助手呢？你也不需要搞清楚它怎么做到的，别人帮你配好了以后你掏钱充值 API 就够了。只要出得起 token 的钱，怎么就不能用了呢？

二、Vibe Coding 的快乐与沟通门槛

我第一次感受到 Vibe Coding 的快乐也是用小龙虾的时候。CodeBuddy 的 IDE 让我对代码太有掌控欲了，但 Vibe Coding 讲究的就是一个不看过程只看结果。只能用手机反而让我更聚焦于如何和 AI 沟通、提需求、下命令，而不是花太多精力在实现上。

当然，即使是和 AI 沟通也有使用门槛，但人的适应性是很快的，你只要用起来，自然就会慢慢掌握一套顺手的沟通方式。起码我认为这个门槛没有高到——你需要会安装小龙虾。

入门替代方案

如果你目前对 OpenClaw 的需求还不足以让你克服安装门槛和 token 支出，可以先尝试以下免费方案体验 AI Agent 的能力边界：

方案 说明

WorkBuddy 开箱即用的本地 Agent（注意安全！）
Claude 官网免费版 即使免费版，给它生成文档、网页之类的任务也会直接帮你做

三、你应该用 OpenClaw 做什么？

3.1 明确工具定位

首先，程序员不能只用 OpenClaw，怎么也得用一下 Cursor、Claude Code 这种专业的 Code Agent。如果你通过 OpenClaw 入门了 Vibe Coding，我也推荐你用更专业的工具去进一步做调整开发。

3.2 OpenClaw 的最佳使用场景

我对比下来，感觉 OpenClaw 最适合做独立的任务调研和定时任务：

  • 定时任务型 OpenClaw： 用 Claude Sonnet 开发好工具以后，运行时换成便宜的 DeepSeek——因为全都开发好以后只是运行任务，非常简单。
  • 调研型 OpenClaw： 长期配 Claude Sonnet 做各种独立任务的调研，有什么新想法都先甩给它去研究一下，写一个 MVP 出来给我看看。

3.3 优势与挑战

优势：

  • OpenClaw 独立解决问题的能力极强
  • 权限极强，自主性极高

挑战：

  • 可能会不断尝试各种方案直到烧光你的 token
  • 安全性较薄弱
  • 期待后续社区有更好的省 token 优化和安全围栏

3.4 使用心法

  • 需要盯着做的任务： 用 OpenClaw 可能会觉得它怎么这么笨、教不会——这时候需要你有耐心地把解决方法教给它，然后让它沉淀成一个 skill，以后类似的任务可以复用。
  • 不想研究的任务： 做成啥样不是很在乎的事情，非常适合丢给它，你只需不时问问进度就行。怎么用也可以让它一步一步教你——你只需要当 AI 老板！

四、OpenClaw vs Code Agent：定位与边界

4.1 工具选型的核心原则

随着体验的深入，我对这两者的使用边界已经划得非常清晰，它们不再是竞争关系，而是互补的”同事”与”管家”：

场景 推荐工具 原因
“从 0 到 1”的大型项目开发 Claude Code / CodeBuddy CLI 几千行代码的系统性构建、复杂的重构任务或涉及 CI/CD 的精准流水线，需要手术刀般的精准和对代码库的绝对理解
“长期在线”的数字生活 OpenClaw 随时在企微/QQ上呼叫的助理，碎片时间里整理思路、监控服务器状态、远程处理小脚本

一个恰当的比喻： OpenClaw 是自动驾驶，Code Agent 是智能辅助——你用哪个取决于你想自己开还是让 AI 开。对于不会开车的人，他们只会选择自动驾驶，只需要决定起点和目的地，由 AI 把他们送到终点。

4.2 省钱策略

随着 AI 的发展，开发程序已经全面拥抱 AI，市面上涌现了太多工具，但好用的往往需要科学上网和一定的花费。国内目前的 MiniMax、GLM 体验下来还有一定差距。

核心省钱策略：把重要的交给更强的模型，次要的交给更简单的模型。 比如你去构建一个 Agent Team，用不同的模型去设定不同的成员——关键决策用 Claude Opus/Sonnet，简单执行用 DeepSeek。

六、我的思考

真正用过就会发现，如何使用 AI，你只要开始了，多多少少很快就可以摸个大概。再深入没必要了——你花老半天研究，人家模型过几个月就更新得更聪明，不需要你那些小技巧了。

The Bitter Lesson 永不过时，人类设定的各种条条框框最终都会被更聪明的 AI 淘汰掉。反而你应该去思考的是——如何用自己已有的知识去构建你特有的工作架构。随着 AI 越来越厉害，你的系统也会越来越厉害。

不要为了今天的 AI 去设计框架，要为未来的 AI 去设计。

关于AI

我看 Claude 创始人离开 OpenAI 创业的故事，提到他因为觉得 OpenAI 不够重视 AI 的安全性而决定自己去做这件事情，提到他的一贯做事风格——

不要跟别人争论他的愿景，如果你有自己强烈的愿景，就去做自己的事。

最近我类似的想法也越发强烈。个人很难抵御历史的洪流，但你可以选择做认可的事情。我始终认为 AI 应该取代人类不想做的杂事，把更多精力留给更重要的、不能被替代的事情。而且 AI 是全人类倾尽资源甚至破坏环境代价下开发出来的，应该受益于全人类——即使没有那么理想，但绝不应该是少数公司把持。

所以要用 AI 去做有用的事情——去打破信息壁垒，消除信息差，去抢夺那些原本只有有钱人能拥有的”智能资源”，让智能像互联网和手机一样普及。

人人都有自己的私人医生、私人助理、行业顾问、研发团队。自动驾驶做 95% 的事情，而人类把握方向盘决定这辆车开向哪儿。

交通工具的发明扩展了人的活动边界，AI Agent 的发展也会扩展人的行为边界。工作不会被完全替代，而是会把人类带向更远的地方。
